首頁 ／ 研究方法

方法論選擇地圖

研究問題分流、方法適配與相對代價

方法沒有絕對的好壞，只有相對的優缺點。這一頁幫你判斷：手上的問題該用哪一種方法，以及每一種方法的代價是什麼；特別把質性研究、設計科學與次級資料三條常被混淆的路徑分開。

一、先問問題的類型，再挑方法

依研究目的，實證研究大致分成三大類：

類型 目的 典型問法 常配的方法
回答明確的問題 用更周延、可靠的方式回答一個是非或程度的問題 「X 對 Y 的預測效果為何？」 問卷調查法、實驗法、次級資料分析
提出新方法或技術 更有效或妥善地解決一個問題 「相較於既有方法，本方法在 ⟨指標⟩ 上表現如何？」 系統發展法／設計科學研究、演算法與最佳化
釐清概念或現象的內涵 探究複雜現象、釐清概念之間的關係 「⟨現象⟩ 是如何發生的？參與者如何理解它？」 質性研究（訪談、個案、紮根理論）

不管是哪一類，實證研究都有一個共同特徵：企圖以可靠的證據為本，透過嚴謹的方法和論證，讓讀者接受自己的主張。

二、資訊管理常見的方法

方法 核心動作 最能回答 最大罩門
問卷調查法 標準化測量、大樣本 變數之間的相關與預測、跨群體比較 橫斷面、單一來源、自陳偏誤
實驗法 操弄自變項、控制外部變項、隨機化 因果關係 外部效度、情境人工化、樣本規模
系統發展法／設計科學 建置人造物並嚴謹評估 「該怎麼設計？」這類規範性問題 評估設計不嚴謹就淪為軟體工程
演算法與最佳化 建模、訓練、比較績效 預測、分類、分群、排程最佳解 資料品質、過度擬合、可解釋性
質性研究 深度訪談、觀察、編碼 機制、脈絡、意義、未被預期的現象 可轉移性、研究者偏誤、難以規模化
次級資料／檔案分析 重新分析既有資料或文件 大規模、長時間或難以自行蒐集的現象 變數、母群體與蒐集品質受原資料限制

混合設計是常態，不是加分項

資管研究常見「量化驗證 + 質性解釋」的解釋性序列設計（Explanatory Sequential Design）：先用問卷找出關係，再用訪談解釋為什麼。 另一種組合是實驗法搭配問卷法：在可操弄自變項、研究問題確實涉及因果時，給予刺激後再以問卷測量結果。若研究問題只問相關或無法合理操弄，這個組合未必有意義。 但要注意：整合的邏輯必須是你的原創論證。為什麼質性結果能解釋量化的異常？這件事 AI 幫不了你。

2.1 質性、設計科學與次級資料怎麼分流

這三條路徑都可能不用發一份新的量化問卷，但研究產出、證據與評估方式完全不同：

先問什麼 選擇方向 核心產出 必須防守的問題
需要理解參與者如何解釋一個尚未釐清的現象嗎？ 質性研究 概念、機制、類型或脈絡化解釋 取樣、反身性、編碼與負例是否可信
研究要建置並評估一個能解決問題的人造物嗎？ 設計科學研究 人造物與可轉移的設計知識 不只是做出系統，還要有嚴謹評估與知識貢獻
問題能用已存在的資料回答，而且原資料的母群體、欄位與品質適用嗎？ 次級資料分析 對既有資料的重新分析與推論 資料生成過程、選擇偏誤、欄位代理與使用權限

若答案是「我要訪談使用者，根據需求做系統，再用既有紀錄比較成效」，那是多階段或混合設計。請逐階段說明每一種證據回答哪一個研究問題，不要只把三個方法名稱並列。

三、因果關係的三個條件

這是選方法時最關鍵的一組判準，也是口試最常被追問的地方：

有相關未必有因果；有因果一定有相關。

要主張因果，至少需要：

  1. 相關性：X 與 Y 確實共變
  2. 時間先後：X 發生在 Y 之前
  3. 排除其他解釋：排除干擾因子（confounding factor）的替代解釋

3.1 干擾因子的經典案例

一個研究者調查數個聚落，發現「每個村落歷年的新生兒數目大致跟該村落的白鸛數目成正比」，於是推論「送子鳥傳說有科學根據」。

實際上：白鸛習慣在屋頂築巢，村落的家戶數愈多，鳥巢與白鸛就愈多；同時家戶數愈多，新生兒也愈多。兩者之間沒有因果關係，只是各自與「家戶數」相關，因而在迴歸分析上呈現高度線性相關。

在仰賴統計分析的研究裡，最怕有未知的干擾因子在誤導分析與結論。 因應策略是：從既有文獻找到較成熟、可靠的理論，作為研究設計、假設與結果分析的依據。

3.2 各方法能主張到什麼程度

你手上的證據 能宣稱到什麼程度 適用動詞
自己的橫斷面路徑係數 相關、預測 預測、與……正相關
自己的實驗（有操弄、有隨機分派） 因果（在該情境與樣本內） 影響、導致
自己的縱貫研究 時序先後、預測後續變化 先於、預測後續變化
引用別人的實驗 依原作者的設計 影響、導致、發現
理論推論（無直接實證） 可能性 暗示、可能、或許指向

橫斷面研究寫成因果，是學術倫理問題，不只是措辭品味。詳見學術中文寫作紀律。

四、方法的相對優缺點：四個範疇

要判斷一個方法適不適合你的問題，把它拆成四個範疇來檢視：

  1. 基礎假設與適用範圍 所有方法的有效性都建基在某些根本假設上。應用場合若高度吻合這些假設，方法才能有預期的表現；一旦嚴重偏離，方法就不適用，實際表現難以預料。 這一項最難彙整：假設可能藏在不易理解的術語裡，可能是被忽略的邏輯意涵，也可能零星散布在好幾篇論文的不同段落。

  2. 應用上的難易程度與成本 時間、經費、設備、樣本可及性、統計軟體、程式能力。

  3. 常態工作條件下的性能表現 在假設成立時，它能達到什麼水準？

  4. 干擾因素與耐受性 哪些因素會破壞它的表現？它對這些干擾有多耐受？

五、研究範圍的剪裁

研究範圍的適當剪裁，會讓研究結果具有較高的客觀可重複性，因此剪裁本身就是攸關研究成敗的關鍵。

要點：

  • 任何答案、解決方案或理論的有效性，都有時間、空間與其他條件上的限制。
  • 如果證據擷取的範圍太廣，超乎該方案的適用範圍，就可能得出前後不一致或矛盾的結果。
  • 審慎比對過去研究成果中的矛盾，往往就能找到適切剪裁研究範圍的辦法。
  • 研究題目與範圍的選擇是一個漸進聚焦的過程，會隨著證據增加而移動、擴大或縮小，不是一成不變的。

宣告範圍的兩難：

  • 宣告的範圍愈大 → 潛在貢獻愈大，但必須舉證防守的地盤也愈大
  • 宣告的範圍愈小 → 防守容易，但可能小到無法滿足學位要求

研究範圍寫清楚後，讀者（含口試委員）才能依照你所宣告的邊界評估研究；超出範圍的問題可作為延伸方向，不宜混同於研究原先承諾回答的內容。

六、方法選擇的決策流程

你的問題屬於哪一類？
│
├─ 想知道「有沒有關係、關係多強」
│   ├─ 需要大樣本、跨群體比較 ────→ 問卷調查法
│   └─ 已有適用且合法可用的資料 ───→ 次級資料分析
│
├─ 想確立「是不是因為 X 才有 Y」
│   ├─ 可以操弄自變項 ────────────→ 實驗法（含準實驗）
│   └─ 無法操弄，但有時序資料 ────→ 縱貫研究／自然實驗
│
├─ 想知道「該怎麼設計、能不能做到」
│   └─ 要產出人造物並評估效用 ────→ 系統發展法／設計科學研究
│
├─ 想「預測、分類、分群或找最佳解」
│   └─ 有可用資料與明確指標 ──────→ 演算法與最佳化
│
└─ 想理解「為什麼、怎麼發生的、當事人怎麼想」
    └─ 現象複雜、學界認識有限 ────→ 質性研究

方法初步選定後，立刻做兩個現實檢查：是否能合法、合乎倫理地取得證據，以及是否有足夠時間與能力完成分析。涉及研究參與者或可識別個人資料時，先看研究倫理與資料管理，不要等資料蒐集前一週才處理。

七、方法論的三個常見錯誤

錯誤一：因為軟體方便就選方法。 PLS-SEM 與 CB-SEM 的選擇要有方法論依據（樣本量、常態性假設、理論成熟度、模型複雜度），不是因為 SmartPLS 或 AMOS 比較好操作。

錯誤二：把方法當成研究的主角。 方法是為問題服務的。先確定問題的形狀，再挑方法。反過來做，就會變成「我學會了某個方法，來找個題目用用看」。

錯誤三：不了解方法的隱藏假設就套用。 最典型的是把先進國情境下發展的制度、量表或技術，機械化地「移植」到不同的情境。它比較像複雜的器官移植手術，必須考慮各種排斥作用與併發症，並設計必要的調適機制。

想取法某一種國外的制度或方法時，必須先考慮它在原情境能發揮優點的先決條件；如果該條件在本地並不具備，就必須調整設計，以便保留原有優點而不衍生意料之外的副作用。

八、研究的信效度不是只有問卷

一句常被忽略的提醒：研究的信效度不是只有問卷的信效度。

當你在論文裡討論一個方法的優缺點時，其實就是在講它的信效度：

  • 資料收集對象是否適合？（誰來填、誰被訪、樣本從哪來）
  • 資料來源是否單一？（單一來源會同時傷害信度與效度）
  • 施測情境是否會系統性地扭曲回答？
  • 時間點是否會影響結果？（例如疫情、政策變動等外部事件）

因此，寫「研究限制」不是認錯，而是在展示你對自己設計的理解深度。

九、本頁重點回顧

  • 先確定問題屬於哪一類（回答問題／提出方法／釐清現象），再挑方法。
  • 方法沒有絕對好壞，只有相對優缺點；關鍵是為問題情境找到最適用的方法。
  • 因果三條件：相關、時序、排除替代解釋。橫斷面只能講預測與相關。
  • 干擾因子是統計研究最大的隱形殺手，理論依據是主要的防線。
  • 研究範圍的剪裁是成敗關鍵；宣告愈大，防守面愈大。
  • 方法的四大範疇：基礎假設、成本、常態性能、干擾耐受性。
  • 討論方法優缺點，本質上就是在討論研究的信效度。
