口試後修訂、典藏與結案

修訂回覆、版本控制、授權送存、離校與研究結案

口試通過只是進入交付階段；這一頁協助你把委員意見轉成可查核的修訂，完成論文送存、授權、離校，以及資料與程式結案。

口頭說通過，不等於所有程序完成

修訂期限、簽核順序、格式審查、論文上傳、紙本份數、授權文件與離校關卡都依各校規定。口試當天或下一個工作日，先向系所與圖書館查證最新版流程；本頁無法替任何學校確認校級細節。

一、口試結束後，先固定原始紀錄

不要立刻憑記憶改論文。先保留一份「口試提交版」，再把口頭意見、書面意見與正式紀錄合併成修訂清單。

  1. 將口試提交的 PDF 設為唯讀，檔名標示版本與日期。
  2. 整理委員逐項意見；聽不清楚的地方標「待確認」，不要自行補成看似合理的要求。
  3. 向指導教授確認哪些是必要修正、哪些是建議，以及誰有權確認完成。
  4. 查明修訂、簽核、上傳與離校期限，記入行事曆。
  5. 若研究倫理計畫仍在執行，確認是否要辦理持續審查、變更或結案。

二十四小時內完成

趁記憶還在，把每一項意見寫成「位置、問題、預計處理、確認人」。兩週後再整理，最容易忘記委員要你改的是文字、分析，還是主張的邊界。

二、建立修訂清單：把意見變成工作項目

一條工作項目只處理一個可驗收的問題。不要只寫「修第三章」或「補文獻」。

ID 委員意見 頁碼／章節 類型 預計處理 狀態 證據
R-01 交代樣本排除規則 3.4、4.1 必要／方法 補排除流程及人數，與分析腳本核對 處理中 修訂版頁碼、commit
R-02 收斂研究限制 5.3 必要／主張 把因果措辭改為預測，補時序限制 未開始 修訂版頁碼
R-03 圖中文字過小 圖 2-1 格式 重製向量圖並核對圖說 未開始 最終 PDF 頁碼

2.1 建議的優先序

  1. 會改變結果或結論的問題：資料、分析、倫理、研究問題與主張邊界。
  2. 會連動多章的問題：術語、樣本數、表格數字、章節結構與引用。
  3. 局部文字與格式：語句、圖表、頁碼、目錄與書目格式。

先處理上游問題。若先排版，後來才重跑分析或重寫結論，往往要再排一次。

三、回覆紀錄：讓每一項都有去處

即使學校沒有要求正式回覆表，也建議保留一份。它可以協助指導教授快速核對，也能避免你只改到表面文字。

欄位 寫法
意見 忠實轉述；不確定處保留待確認標記
回覆 先說是否採納，再說理由
修改內容 說明改了什麼，不只寫「已修正」
位置 最終版章節、頁碼、表號或程式檔
未採納理由 以證據、研究範圍或方法限制說明，先與指導教授確認

可用句型：

感謝委員指出 ⟨問題⟩。本次已於第 ⟨章節⟩ 補充 ⟨內容⟩，並同步修正第 ⟨連動位置⟩，使 ⟨研究問題／分析／結論⟩ 一致。修改後的主張限於 ⟨範圍⟩。

經與指導教授確認，本項未直接採納，理由是 ⟨證據或設計限制⟩。為避免讀者誤解，已在第 ⟨章節⟩ 明確說明 ⟨邊界或限制⟩。

不要把回覆寫成辯論。委員意見彼此衝突時，列出衝突與影響，交由指導教授決定，不自行挑最省事的一條。

四、版本控制：永遠保留可回復的提交版

論文、資料與程式要能回答兩個問題：現在的正式版本是哪一個？它和口試版差在哪裡？

4.1 最低限度做法

thesis/
├── 00_submitted/       # 口試提交版，唯讀
├── 01_revision/        # 修訂中的來源檔
├── 02_final/           # 確認後的交付檔
├── response-log.md     # 修訂清單與回覆
└── CHANGELOG.md        # 日期、修改者、摘要、確認人
  • 檔名用日期或版本號，不用「最終版」「最終版2」「真的最終版」。
  • Word 使用者可搭配追蹤修訂與 PDF 比對；純文字、LaTeX 或程式專案可使用 Git。
  • 每完成一組可說明的修訂就留存一次，不要把全文改完才做唯一的版本紀錄。
  • 最終確認後凍結來源檔與 PDF；若重新輸出 PDF，重新做全文檢查。

4.2 最終版一致性檢查

  • 封面、書名頁、審定書、摘要的題名與姓名一致
  • 目錄、圖目錄、表目錄、頁碼與交叉引用已更新
  • 正文引註與參考文獻雙向對得上
  • 表格、附錄與正文中的樣本數及統計值一致
  • 修訂後的研究問題、結果、討論與結論逐題對應
  • PDF 可搜尋、字型與公式正常、連結可開啟、無批註與追蹤修訂殘留

五、格式、著作權與授權分開處理

5.1 格式依各校最新版規定

紙張、邊界、字型、書背、審定書格式、電子檔命名、紙本份數與繳交順序都可能不同。請向系所、教務單位與圖書館核對，並記錄查證日期；本站不提供通用數字。

5.2 引用他人不等於取得重製權

著作權保護具體表達，不保護觀念、方法、程序與事實本身。用自己的話整理觀念並適當引註，和直接重製他人的圖、表、量表、照片或大段文字，是兩個不同問題。

  • 引註處理學術歸屬，不一定同時取得重製或改作的授權。
  • 第三方圖片、量表與非短篇引文，依權利狀態確認是否須取得許可。
  • 已取得許可的材料，保存授權範圍、版本、用途與期限的證明。
  • 不能公開的材料可改為自己的分析、合法短引，或在不影響論證下移除；不要假設「放在學位論文就一定可以」。

私人資料必須移除，但不是所有有著作權的內容都要刪除

最終公開版應移除或隱蔽 Email、電話、住址、身分證字號、未經同意的簽名與其他不必要的個人資訊。另一方面，合理引註、依法使用或已獲授權的內容可以保留。隱私、著作權與契約義務要分別判斷，不能用同一種清理規則處理。

5.3 論文授權要看清楚範圍

論文著作權、學校或國家圖書館的典藏送存，以及讀者能否下載全文，是不同層次。簽署前確認：授權對象、利用方式、地域、期間、是否專屬、電子全文開放日，以及日後變更程序。若另對資料或程式套用開源授權，確認你有權授權其中所有內容。

六、典藏、延後公開與離校

依 2026 年 1 月修正的「大專校院學位論文送存國家圖書館典藏作業要點」，學位論文由學校送存國家圖書館，電子全文送存時應檢附授權書；論文中的 Email、電話、住址、身分證字號等個人資訊應抽出或隱蔽。延後公開限於涉及機密、專利事項或依法不得提供等情形，且須經學校權責單位認定、備妥簽章與證明，再由學校提出。

這是國家圖書館送存層級的要求。你實際操作的系統、表單、審查、紙本與離校順序，仍依各校規定。

6.1 送存前流程

  1. 查證：下載本學期的系所格式、圖書館上傳與教務離校規定。
  2. 確認版本：取得指導教授或指定單位對修訂版的確認。
  3. 產出 PDF：依規定加入審定書與必要文件，移除批註及不應公開的個資。
  4. 核對書目資料：中英文題名、作者、指導教授、關鍵字與摘要要和 PDF 一致。
  5. 閱讀授權文件：分清典藏、館內閱覽、電子全文下載與延後公開。
  6. 完成校內審核：修正退件項目後，再印製或辦理後續程序。
  7. 保存收據與證明：上傳核准、紙本繳交、授權與離校完成畫面各留一份。

以下校級細節一律待查證

上傳截止日、審核所需工作天、紙本份數、精裝或平裝、審定書是否需正本、授權書簽署方式、論文抽換程序、延後公開校內審議、畢業證書領取與離校系統關卡，均依各校當學期規定。

七、資料與程式結案

論文交出去，不代表研究資料可以留在個人電腦裡無限期保存，也不代表全部上傳公開才算透明。結案要回到倫理核准、知情同意、資料提供契約、經費規定與所屬機構政策。

7.1 資料結案

  • 確認 IRB／REC 是否要求結案報告、成果摘要、偏差或事故通報。
  • 依核准期限保存、移交或銷毀聯絡名單、同意書、錄音、逐字稿、問卷與代碼表。
  • 移除已離開團隊者與臨時協作者的存取權限。
  • 留下資料清單、資料字典、權限紀錄、備份位置與到期處理日期。
  • 研究參與者資料若不能安全公開，就不要放進論文附件或公開儲存庫。

7.2 程式與重現套件

  • 固定最終分析程式、亂數種子、套件版本與執行順序。
  • 提供 README，說明如何從可分享的輸入得到論文中的表與圖。
  • 移除密碼、API 金鑰、絕對路徑、帳號、暫存檔與未授權資料。
  • 以乾淨環境實跑一次；若不能公開原始資料，提供合成資料、資料結構或申請方式。
  • 為自己有權授權的程式選擇授權；第三方程式與資料保留原授權及出處。

刪除前先確認保存義務

銷毀資料可能是倫理承諾，也可能與稽核、申訴或研究誠信的保存要求衝突。不要只因為完成離校就整批刪除。先由指導教授或計畫主持人依正式規定確認，再留下銷毀項目、方式、日期與執行人的紀錄。

八、最後四十八小時的交付清單

  • 每一項口試意見都有回覆、位置與完成證據
  • 指導教授或指定確認人已核可修訂版
  • 最終 PDF 通過格式、搜尋、字型、連結與個資檢查
  • 圖表、量表、照片與長篇引文的權利狀態已確認
  • 書目資料、PDF 與授權文件內容一致
  • 校內上傳、紙本、授權、典藏與離校關卡皆有完成證明
  • IRB／REC 結案或後續追蹤狀態已確認
  • 資料保存／銷毀日期、責任人與位置已記錄
  • 程式與重現套件已去除機密並在乾淨環境驗證
  • 口試版、修訂紀錄、最終來源檔與最終 PDF 各有獨立備份

把最終交付包設為唯讀，並在檔案清單中記下雜湊值或至少記錄檔案大小與產出時間。日後發現錯誤時，先查學校的抽換或更正程序，不直接覆寫已送存版本。

九、本頁重點回顧

  • 口試後先固定提交版，再把每一項委員意見轉成可驗收的修訂工作。
  • 回覆紀錄要寫修改內容、位置與證據，不只寫「已修正」。
  • 保留口試版、修訂版與最終版；任何重新輸出的 PDF 都要重新檢查。
  • 格式、著作權、個資、論文授權與典藏是不同關卡，應分別處理。
  • 私人資料必須移除；著作權保護表達而非觀念，不是所有有著作權的內容都必須刪除。
  • 典藏與離校的校級細節依各校規定；不確定的期限、份數、簽章與程序均須查證。
  • 資料與程式依倫理核准、同意、契約及機構政策結案；敏感資料不能為了重現性而直接公開。
