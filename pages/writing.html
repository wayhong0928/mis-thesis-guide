首頁 ／ 論文寫作

論文架構與各章寫作要領

六大部分的功能、寫作次序與台灣碩論慣例

論文寫作本質上是一場攻防戰。你不只要讓讀者相信這個研究的成果，還要預先設想他們可能的質疑，把自己的主張防衛得滴水不漏。

一、六個主要部分與它們的分工

不管是哪個學術領域、量化或質性、學位論文或期刊論文，以實證研究為基礎的論文通常包含六個部分：

摘要 → 導論／緒論（含問題背景與文獻回顧）→ 理論依據、研究方法與架構
     → 結果、分析與討論 → 結論與未來研究建議 → 參考文獻

這六個部分內容或許有些重疊，但各有明確的功能與角色，且彼此相銜、前後呼應。如果只是依樣畫葫蘆抄襲主題相近的論文架構，很容易畫虎不成反類犬。

部分 核心功能 常見失誤
摘要 像廣告文宣，也像一張必須兌現的支票 平淡無奇看不出特色；或誇大到論文兌現不了
導論／緒論 說服讀者這個主題重要，且本研究有必要 文獻鳩占鵲巢；或把研究情境寫太死
文獻探討 描繪知識邊緣、釐清本研究與文獻的關係 只敘不評的流水帳
理論與方法 論證「為何這麼做」，並讓人能複製 只寫怎麼做，不寫為什麼
結果與討論 呈現證據，逐步論證到最終結論 證據到哪裡，結論跳到更遠
結論 客觀總結貢獻與限制 複製貼上導論；或誇大貢獻

二、寫作次序：不要照著章節順序寫

建議的順序：

① 導論初稿（粗略）
   ↓
② 理論依據與研究方法
   ↓
③ 結果與討論
   ↓
④ 回頭細修導論並定稿
   ↓
⑤ 最後才寫結論
   ↓
⑥ 最後的最後才寫摘要

理由很簡單：

  • 摘要的字數最少、篇幅限制最嚴苛，因而是最難寫的部分。
  • 只有當方法與結果都寫完，你才確知這個研究有哪些可靠的成果與特色，回頭改導論時思緒才會清晰、下筆才會篤定。
  • 導論定稿之後，整篇文章的重點與精華已經徹底釐清且濃縮過，這時候寫摘要才容易掌握。

質性研究的寫作是另一回事

社會學的寫作經常涉及極為複雜的概念與事實，「成竹在胸、一氣呵成」的模式並不適用。 寫作是釐清思緒的唯一方法，唯有一再改寫才能逐漸釐清思緒，並同步摸索出論文的適當架構與內容的最佳剪裁。

2.1 寫作的最小可交付單位

寫作次序解決「先寫哪一章」，但多數人卡住的其實是每天要交出什麼。

「今天要寫第二章」是一個沒辦法完成、也沒辦法宣告完成的目標，所以它每天都會被延後。把它換成最小可交付單位：

❌ 今天寫第二章 ✅ 今天把 ⟨某個構念⟩ 那一節的論證鏈寫完（約 400–600 字，三層結構跑完一輪）

一個好的最小單位有三個特徵：一到兩小時做得完、做完看得出來、可以直接貼進論文。

三個配套習慣：

  • 用純文字起草，最後才轉排版。 Markdown 或任何純文字工具都行；在 Word 裡邊寫邊調格式，會讓你把注意力花在錯的地方。
  • 給指導教授看之前先大聲唸一遍。 中文學術寫作的流暢度問題，用眼睛看很難抓；唸出來卡住的地方，通常就需要修改。
  • 引用格式從第一天就管好。 「之後再整理」的代價是最後一週重排一百多筆參考文獻，而且一定會出錯。做法見文獻管理與知識庫。

計畫書就是初稿的骨架

如果你已經寫過研究計畫書，論文不是從零開始：計畫書的研究背景與問題 → 第一章；文獻整合 → 第二章（每一節從「這篇文獻能幫我說什麼」出發擴充論證，不是堆砌摘要）；假說與模型圖 → 第三章核心，補上操作型定義、抽樣設計、資料蒐集流程與分析步驟；量表 → 附錄。 把計畫書各節對應到論文各節，你會發現剩下的是擴充，不是創作。

三、下筆前的三個準備動作

3.1 盤點研究成果，選定論述重點

《孫子兵法》說「勝兵先勝而後求戰」。論文寫作也是如此：先營造有利於自己的形勢，等到立於不敗之地，才開始作戰。

具體作法：

  1. 遴選一個學術界既存的觀點、主張或方法，作為你準備要挑戰或補足的對手
  2. 盤點自己的證據與論證，看是否足以在某個適用範圍內駁倒或補足它
  3. 同時盤點有利於對方的文獻與證據，揣想對方可能會如何答辯
  4. 確定自己有十足勝算時，再把這些攻防的盤算整理成論述策略與論文架構

兩大好處：聚焦明確，容易突顯重要發現；焦點越明確，越有機會論證得深入且嚴謹。反之，議題與範圍太寬泛，容易讓讀者失焦，也容易流於泛論。

定位錯誤的代價

一篇後來成為社會學經典的論文，第一次投稿時被直接退稿，因為作者把它包裝成對某個既有理論的再探討，而評審認定他誤解了那個理論。 他把該理論的討論全數移除、徹底聚焦在自己真正的貢獻上之後，論文被頂尖期刊接受。 研究成果即使富有原創性，定位錯誤仍可能使評審無法看見貢獻；重新定位也可能讓原本不突出的成果獲得較合適的解讀。

3.2 建立論證的層次架構

把主要結論與研究發現逐一寫下來，先不管輕重與先後。接著分析它們之間的內在邏輯關係：

證據 ─┐
證據 ─┼→ 小結論 ─┐
證據 ─┘           ├→ 中間層次結論 ─┐
證據 ─→ 小結論 ─┘                  ├→ 最終結論
證據 ────────────────────────────────┘

一邊釐清結論之間的關係，一邊自問：你是依據哪些證據和論證過程獲得這些結論的？ 可以為每一個小結論與中間結論各建一個檔案，摘要寫下它所憑據的證據、假設（條件與適用範圍）與主要論證過程。

3.3 挑三到五篇最接近的近期論文當參考

理由有三：

  1. 用它們合併起來覆蓋「本研究最鄰近的既有文獻邊界」，就能斷定你確屬原創的部分
  2. 從中彙整對其他理論、方法、證據的批判，同時用來為自己的選擇辯護
  3. 主題、範圍與方法相近時，論文結構與章節次序也會有許多雷同處，可供參考

四、緒論／導論的寫作要領

導論必須承載三大任務：

  1. 介紹研究主題、背景及其在學術與應用上的重要性，讓讀者相信它值得被研究。
  2. 回顧學術界過去的研究，扼要評價得失，指出至今仍待解決的部分，並明確說明本研究如何跟既有文獻區隔、如何填補不足。
  3. 扼要敘述本研究擬採用的觀點、理論、方法與資料來源，以及它們相對於既有文獻的優點。

有些作者還會加上兩個功能：預告主要研究成果，以及簡介後續章節的內容與次序。

4.1 兩種常見的論述架構

架構 A：從矛盾切入（適合「為既有問題提供更可靠答案」的研究）

① 突顯既有研究結果之間的矛盾
② 指出造成矛盾的可能成因與既有方法的缺失
③ 提出本研究的對策與特色

架構 B：從技術缺口切入（適合「改良既有方法或技術」的研究）

① 扼要陳述研究主題的重要性
② 分析既有方法（流派）的主要缺點與可能成因
③ 提出本研究的對策與優點

4.2 兩個關鍵紀律

紀律一：檢視既有文獻的不足時，要聚焦在跟本研究貢獻相關的部分，而不是長篇大論臚列一堆本研究也無法解決的問題。

紀律二：導論的主角只有兩個，也就是研究主題的意義與價值，以及本研究在觀點、理論、證據與方法上的創新。既有文獻是佐證用的配角，不該鳩占鵲巢。

第一印象決定大半評價

研究顯示，很多審查委員在讀完摘要與導論之後就已經對論文有初步評價，而這個第一印象跟讀完全文後的評價常常相去不遠。 如果導論遺漏重要文獻，表示見識淺薄；論述雜亂無章，表示囫圇吞棗；只是流水帳臚列而沒有一針見血的得失評價，表示欠缺洞見與批判力。

五、理論依據與研究方法

要先分清楚兩件事：

  • 研究方法（research method）：描述你如何（how）做，包括產出研究結果的方法、程序與步驟。
  • 理論依據與方法論的考量（methodology）：論證你為何（why）這麼做，提出充分理由，把你的方法、策略與研究架構合理化。

5.1 方法章的兩個任務

任務一：讓人能複製。 必須清晰交代整個研究的方法與步驟，讓同領域的專家能據以複製出相同的結果。至少要交代：

  • 原始資料的擷取環境（資料庫名稱與來源、設備、受訪者來源與徵集過程、觀察地點與情境）
  • 時機（施測或採樣時間，以及可能影響結果的其他時空、心理、環境因素）
  • 方法與步驟（抽樣準則、實驗程序、訪談情境與步驟）
  • 資料的後處理與數據化程序（清理規則、不當資料的剔除、逐字稿編碼）
  • 數據的處理與分析（統計方法、軟體、參數設定、分析步驟）

任務二：夾敘夾評，預先回答質疑。 方法章不能只有敘述，還要有客觀的自我批判與評論。一邊敘述「我們這麼做」，一邊論述「為什麼這麼做、為什麼不採其他替代方案、我們知道有哪些潛在疑慮、為什麼它們不會影響主要結論」。

讀者能想到的替代辦法，作者基本上都想到了，並且在論文中說明了不選擇它們的理由。

5.2 可重複性與可讀性的平衡

在追求可重複性的同時，必須維持論文的可讀性。原則是：

  • 對結果有重大影響的程序、步驟和數據 → 詳細寫
  • 既有的標準處理程序或資料庫 → 引註參考文獻即可
  • 次要的敘述 → 放到附錄
  • 過分瑣碎、有礙思緒的細節 → 捨棄

這些取捨往往反映作者對研究主題的專業判斷能力。下筆前找三五篇主題與方法都相近的論文參考，斟酌哪些可以簡略、哪些必須詳述。

六、結果與討論

「結果的分析與討論」與「研究的方法與步驟」在結構上前後相銜，在論證上必須緊密扣合。

6.1 一個重要的紀律

證據顯示到哪裡，推論就進展到哪裡，絕不在證據不足時跳躍地妄下結論。

這是不分學科與研究類型都必須恪守的軌範。

6.2 結果章的內部結構

它雖然只是一個章節，內部結構卻十足是一篇小論文：

  1. 呈現主要的結果（證據）
  2. 跟既有文獻的發現相連結或比較異同
  3. 根據這些證據進行分析與論證，逐步導向最終結論
  4. 過程中夾敘夾評，闡述各項發現的得失、意義與價值

6.3 沒有明確結論的發現怎麼處理

研究過程往往會出現未曾預料的線索、證據或疑點，而且無法在結案時充分釐清。處理方式：

  1. 把它們跟成熟的結論明確區分開來
  2. 先描述、分析、論證可以有確切結論的結果
  3. 之後才擇要報告無法做出確切結論的發現與疑點
  4. 評估它們潛在的意義與價值，以及對本研究結論可能的影響
  5. 建議未來研究如何加以釐清或改善

不要隱瞞缺點或過度防衛

在學術界會被視為「欠缺客觀衡量個人研究成果的能力」，等於暴露學術能力的不足。 論文只需要有適當的貢獻，不需要完美無瑕。「誠實」是科學與學術研究的第一守則。

6.4 比較基準的選擇

數據的真實意義，往往只有在恰當的比較基準下才會正確顯露出來。一旦比較基準不當，意義就會被扭曲。

三個常見的陷阱：

  1. 絕對值 vs 相對值：兩個國家的確診人數，總人口相差五倍時就不能直接比。應改用「每百萬人口」。
  2. 量測誤差與平滑化：只挑最高點那一天的數據來比較，很容易被通報延遲等量測誤差誤導。學術界往往先做移動平均再比較。
  3. 衡量指標與直覺不符：一個「概念模糊、跟直覺概念有遙遠距離」的指標，很容易傳遞錯誤訊息，讓人得出相反的結論。

當研究主題牽涉的因素越複雜，比較基準也必須相對夠複雜、周延，才能得出合理的結論。 若無法窮盡所有因素，就明確宣告「在不考慮其他因素的影響下」進行研究與結論。

6.5 資料視覺化

設計得當的圖表是突破難題的關鍵利器；設計不當時，也可能成為誤導讀者的亂源。

必備元素（很多碩論初稿都缺）：

  • 圖表編號與名稱
  • 橫軸與縱軸的變數名稱、單位與尺規（線性、對數或半對數）
  • 每一條曲線的屬性標示、每一欄位的名稱與單位
  • 正文中對圖表關鍵內容的提示、補充說明與評論

選對座標軸的變數，訊息才會浮現

一張比較兩百多年來小麥價格與工資變化的經典圖表，因為縱軸變數選得不好，看不出作者想傳遞的訊息。 把縱軸改成「購買固定份量小麥所需的工時」之後，「實質工資大幅提升」這個結論就一目了然。 同一組數據，換一個縱軸就換一個故事。 這是視覺化最重要的一課。

一個常見的碩論疏漏：把圖表丟進論文卻不在正文中引導。一張圖表的資訊極其豐富，沒有作者的文字引導，讀者不可能知道你想表達什麼。

6.6 案例的選擇與排序

「代表性」通常指下列幾種之一：

  • 介於最常見與最極端的數種案例
  • 介於最有利與最不利的數種案例
  • 介於結論最明確與最不明確的數種案例

排序策略：由簡而繁（先比較假設較單純、容易說明的案例，再慢慢增加複雜度），或由不利到有利（先證明「即便在無法發揮本方法優勢的情境下依然略勝一籌」，再用最貼近實際應用的情境證明大幅領先）。

七、摘要

摘要必須在極短篇幅內依序交代五個重點：

  1. 研究的主題
  2. 既有文獻的關鍵缺失或不足（等於本文企圖解決的課題）
  3. 本研究所採用的方法
  4. 最關鍵、最吸引人的研究成果
  5. 精簡的結論

措詞必須直白、句句精要、直指核心，完全沒有花俏修辭的空間，更容不下廢話。

它同時是廣告文宣，也是一張必須立即兌現的支票：

  • 太平淡 → 讀者懷疑這篇論文乏善可陳
  • 過度誇大 → 作者有不誠實的嫌疑，或嚴重欠缺客觀評價研究成果的能力

開始下筆前，拿出跟本研究最相近的論文當參考，看看它們的摘要是如何架構與措詞的。

八、結論

一篇論文的結論通常比導論短、比摘要略長，且分成數段。

結構：

  1. 精簡重提研究主題與方法，扼要總結主要發現和結論 （內容在導論已提過，但語氣從「預期的結果」變成「確實的結果」，不應該只是複製貼上）
  2. 扼要說明這些發現對學術界或產業界的主要貢獻 （像簡答題而不是申論題。若擔心太簡潔不足以讓讀者明白貢獻，該補充的是導論與結果與討論，而不是結論）
  3. 扼要指出研究的主要限制、適用範圍與不足處，並建議未來如何擴充、發展與改善

最重要的要領：儘管結論是在檢討自己的貢獻與不足，行文語氣必須像是公正的第三者。對自己的貢獻既不誇大也無須謙詞，對缺失無須迴避也沒必要語帶歉意。

研究限制寫得深刻，是加分項

學位論文不宜省略研究限制，因為這是你表現批判性思考與專業成熟度的另一個機會。 寫得深刻而有見地，會有加分的效果；寫得敷衍（「本研究樣本數較少」然後就沒了），反而暴露你沒認真想過。

九、台灣碩論的章節慣例

第壹章　緒論
  第一節　研究背景與動機
  第二節　研究目的與問題
  第三節　名詞釋義（有些系所放在第三章）
  第四節　研究流程（或研究範圍與限制）

第貳章　文獻探討
  第一節　XX 理論與相關研究
  第二節　XX 理論與相關研究
  …
  末　節　研究缺口與小結

第參章　研究方法（或研究設計與實施）
  第一節　研究架構（含架構圖）
  第二節　研究假說
  第三節　操作型定義與測量工具
  第四節　研究對象與抽樣方式
  第五節　資料分析方法
  第六節　研究倫理

第肆章　研究結果與討論（或分成兩章）
  第一節　敘述統計
  第二節　測量模型評估
  第三節　結構模型分析
  第四節　假說驗證結果

第伍章　結論與建議
  第一節　研究結論
  第二節　理論貢獻
  第三節　實務貢獻（或管理意涵）
  第四節　研究限制
  第五節　未來研究方向

注意事項：

  • 章用國字大寫（壹貳參肆伍），節用一般中文數字（一二三四五）
  • 用「文獻探討」，不用「文獻回顧」或「文獻綜述」（後者偏大陸用法）
  • 用「研究方法」，不用「研究方法論」（methodology 的層次留給博士論文討論）
  • 計畫書（proposal）通常只寫到第參章，加上預期貢獻與研究限制

9.1 各章的參考頁數（碩論）

章節 建議篇幅 說明
研究背景與動機 5–10 頁 要講清楚研究問題的重要性
文獻探討 15–20 頁 要有最近五年文獻，管理類建議做比較表
研究方法與設計 10–15 頁 架構、假說、操作型定義、抽樣、分析方法

（實際頁數依系所與指導教授要求調整，此處僅為常見的參考值。）

十、論文的完整樣貌與裝訂次序

國內大學常見的規定順序：

封面 → 口試委員審定書 → 致謝辭（非必要）
→ 中文摘要及關鍵詞 → 英文摘要及關鍵詞
→ 正文目次 → 插圖目次 → 表格目次
→ 論文正文 → 參考文獻 → 附錄（非必要）→ 封底

實際格式一律以所屬系所的規定為準。

10.1 參考文獻清單的態度問題

學位論文篇幅可觀，錯別字往往難免，多數口試委員也較能寬容。但參考文獻清單通常只有數頁，如果連這幾頁都無法仔細訂正，往往會被認定為態度草率。

口試委員常做的檢查：隨機挑幾則參考文獻，確認正文中的引註與文末清單確實吻合，而且格式前後統一，包括標點符號的正確性、位置，以及標點後是否有空白格。

10.2 致謝辭與共同作者

該被感謝的對象包括：對論文品質有直接助益的師長、提供儀器設備或環境的單位、協助發放問卷與編碼的學弟妹、口試委員、獎學金提供者。

若是共同掛名，國際上較務實的三項要件是：

  1. 對論文有重大貢獻（研究構想與設計，或資料的擷取、分析與詮釋，或撰寫與重大改寫）
  2. 仔細讀過完稿全文並同意其出版
  3. 對自己的貢獻負責，並確保跟個人貢獻無關的部分也已被其他人適當處理

有貢獻但無法滿足這三項的（提供經費、場地、設備、被動諮詢），只適合列名於致謝辭中。

十一、措詞：「寄出」與「送達」的差別

一封平信只能叫「寄出」（send），因為對方不一定收到；掛號並確知對方收到，才叫「送達」（deliver）。

如果使用者手冊中的訊息讓許多讀者讀不懂，這份手冊就沒有「送達」訊息。這是誰的錯？當然是撰稿者的錯。

同樣的，如果論文有任何措詞、段落讓學長姊讀不懂，或覺得論述太牽強、薄弱，就必須修改到他們能理解、認同，才算達成最起碼的任務。

改善辦法：

  • 寫完初稿後反覆重讀，揣摩讀者可能的反應，改到順口為止
  • 請學長姊幫忙讀，請他們挑出讀起來不順或不夠清晰的地方，並講出自己的理解
  • 句子太糾纏時，把裡面的概念分解成幾個簡單句子，再用最後一句整合
  • 有時候只要調換次序，把單純易懂的放前面，把引用前述思想的放後面，文句與思路就會同時通暢

十二、本頁重點回顧

  • 論文六大部分各有功能，彼此呼應，不能依樣畫葫蘆。
  • 寫作次序：導論初稿 → 方法 → 結果 → 回頭修導論 → 結論 → 摘要。
  • 下筆前先選定論述重點、建立論證層次、挑三五篇最近的參考論文。
  • 導論的主角是研究的價值與本研究的創新；文獻是配角。
  • 方法章要能被複製，也要夾敘夾評、預先回答質疑。
  • 證據到哪裡，推論就到哪裡。 誠實是第一守則。
  • 比較基準與座標軸的選擇會決定數據講出什麼故事。
  • 摘要是廣告也是支票；結論的語氣要像公正的第三者。
  • 研究限制寫得深刻是加分項；參考文獻的格式是態度問題。
  • 論文要「送達」而不只是「寄出」。
