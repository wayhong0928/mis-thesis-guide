# 演算法、最佳化與資料分析

> 演算法處理「如何解題」，最佳化處理「如何讓結果更好」。兩者常被混為一談，但在論文的方法章裡，它們是兩組不同的設計決策。

若尚未修過機器學習，先查閱[核心名詞速查](glossary.md)再讀。本頁是協助選擇問題類型、方法與驗證方式的地圖，不是演算法實作教材。

---

## 一、兩個概念的本質差異

**演算法**處理的是「如何解題」：給定輸入，依照一組明確且可重複執行的步驟，得到輸出。這個步驟可以是決策樹的分支判斷、K-means 的距離計算，也可以是神經網路逐層的矩陣運算。只要流程確定，演算法就能執行。

**最佳化**要問的問題不一樣。它假設模型已經有了，但參數空間太大無法逐一嘗試，因此必須設計一種有效率的搜尋方式，在限制條件下找到讓**目標函數**最小（或最大）的參數組合。

最簡單的對照：**神經網路的架構是演算法，訓練它的梯度下降是最佳化。**

!!! note "為什麼這個區別對論文很重要"
    當一篇論文說「採用 LSTM 模型」，這是**建模選擇**；當它進一步說明用 Adam 最佳化器、學習率設多少、跑幾個 epoch，這才進入**最佳化**的層次。
    兩個部分的設計決策都會影響結果，卻常常被混在一起描述，導致**可重現性下降**。方法章要把它們分開交代。

## 二、資料分析問題的類型

問題類型直接決定了方法的選擇方向，選錯類型就全錯。

| 類型 | 目標 | 資料要求 | 典型資管應用 |
|---|---|---|---|
| **分類（classification）** | 判斷一筆資料屬於哪一個類別 | 有標籤 | 虛假評論偵測、流失預測、風險分級 |
| **迴歸（regression）** | 預測連續數值 | 有標籤 | 銷售量預測、停留時間預測 |
| **分群（clustering）** | 讓演算法自行找出資料的內在結構 | 無標籤 | 客群分析、使用者類型區分 |
| **關聯規則** | 找出項目之間的共現關係 | 交易紀錄 | 購物籃分析、推薦 |
| **最佳化** | 在限制下找最好的組合或路徑 | 目標函數與限制式 | 排程規劃、路徑最短化、資源配置 |

**最佳化在這個框架中是獨立的一類問題**，性質與分類、迴歸截然不同，選方法時不能混用。

## 三、建模方法的三條路線

三條路線對應不同的資料條件與研究需求，**不存在哪條路線「更好」的問題。**

### 3.1 監督式學習

需要標註好的訓練資料。常見方法：線性迴歸、邏輯迴歸、決策樹、隨機森林、支援向量機、整體學習（ensemble learning）。

**整體學習的兩大路線**：

| | Bagging（如隨機森林） | Boosting（如 AdaBoost、XGBoost） |
|---|---|---|
| 做法 | 對資料進行**隨機重抽樣**，多個模型平行訓練後投票 | **提高錯誤樣本的權重**，讓後續模型專注學習困難資料，序列式訓練 |
| 傾向 | 降低變異，**不容易過度擬合** | 降低偏誤，**可能過度擬合** |
| 適合 | 資料雜訊較多時 | 資料乾淨、需要高準確率時 |

方法選擇必須配合**資料本身的雜訊程度與樣本分布**，這一點要在方法章交代。

### 3.2 非監督式學習

不需要標籤，讓演算法自行找結構。

**K-means 分群**的四個步驟：

1. 初始化群中心
2. 將資料分配到最近的中心
3. 更新群中心
4. 重複直到收斂

適合客群分析、使用者分型、個人化推薦的前置分群步驟。要注意 k 值的選擇必須有依據（肘部法、輪廓係數、理論考量），不能隨便設。

### 3.3 深度學習

| 架構 | 核心機制 | 常見用途 | 注意事項 |
|---|---|---|---|
| **CNN** | 卷積層萃取局部特徵；池化層壓縮雜訊，保留最具代表性的特徵 | 影像辨識、短文本分類 | 對序列的長距離依賴處理有限 |
| **RNN** | 把前一次的計算結果與這次的輸入一起納入考量 | 序列資料 | **梯度消失／爆炸**會導致「失憶」 |
| **LSTM** | 用遺忘閘、輸入閘、輸出閘控制資訊流 | 評論分析、情感分析、時間序列 | 訓練成本較高 |
| **Transformer** | 自注意力機制，可平行處理長序列 | 自然語言處理主流 | 資料與算力需求大 |

深度學習的優點是**特徵萃取能力強，不需要人工設計特徵**；代價是計算資源需求高，且**可解釋性相對有限**。在需要向管理層解釋預測依據的資管情境中，這是尚未完全解決的問題。

### 3.4 文字的向量表達

| 方法 | 原理 | 特性 |
|---|---|---|
| 詞袋模型（Bag of Words） | 統計詞頻，忽略順序 | 簡單、可解釋，但語意資訊少 |
| n-gram | 把文字切成連續的 n 個字／詞為一單位 | 保留局部順序，特徵維度爆炸 |
| TF-IDF | 加權詞頻，降低常見詞的權重 | 常見基準線 |
| Word2Vec／GloVe | 學習詞的稠密向量表示，語意相近的詞距離近 | 效果通常明顯優於詞袋 |
| 預訓練語言模型嵌入 | 上下文相依的向量 | 效果最好，成本最高 |

一個穩定的實證結論：**詞袋模型效果通常較差，分散式向量表示（如 Word2Vec 以上）效果明顯較好。** 但論文中仍應把詞袋當作基準線一起報告，讓改善幅度有對照。

## 四、最佳化方法

### 4.1 梯度類方法

**梯度下降法（Gradient Descent）**：計算目標函數對每個參數的梯度，往梯度的反方向調整一小步，重複到損失函數夠小為止。

**學習率是最關鍵的參數**：設太大容易震盪不收斂，設太小收斂極慢。通常需要實驗反覆調整，而且**調整過程要寫進論文**。

**Adam（自適應動量估計法）**：根據歷史梯度資訊自動調整每個參數的學習率，收斂速度與訓練穩定性明顯優於基本梯度下降，是目前深度學習最廣泛使用的最佳化器之一。

### 4.2 啟發式最佳化

當問題**不可微分、目標函數不連續、或限制條件極複雜**時，梯度類方法就失效了。這時才需要啟發式方法。

**遺傳演算法（Genetic Algorithm）**的迭代循環：

1. 初始化族群
2. 計算適應度
3. 選擇
4. 交配
5. 突變
6. 重複迭代至收斂或達到終止條件

適合：排程、路徑規劃、組合最佳化。
優點：可處理大規模、非線性、複雜問題。
代價：**不保證找到全域最佳解**，只能在可接受的計算資源內找到夠好的近似解，且計算成本明顯高於梯度下降類方法。

其他常見的啟發式方法：模擬退火（Simulated Annealing）、粒子群最佳化（PSO）、蟻群演算法。邏輯各異，但共同點都是「不保證全域最佳、只求夠好」。

## 五、實驗驗證的流程

方法選完之後，怎麼驗證它有沒有效，是方法論中同等重要的環節。

```
資料蒐集
  → 前處理（清理、補值、去重、標準化）
  → 特徵工程
  → 資料切分（訓練集 / 驗證集 / 測試集）
  → 模型設定與訓練
  → 最佳化與調參（只能用驗證集）
  → 測試集評估
  → 結果分析與比較
```

### 5.1 資料切分是防止過度擬合的關鍵

**測試集必須在整個訓練過程中完全隔離**，不能在調參時「看到」它的表現，否則評估結果會高估模型的泛化能力。

這件事在資管研究中並非總被嚴格處理。很多論文其實是用測試集調參，再回報測試集的成績。方法章要明確寫出切分比例、切分方式（隨機／分層／時間序），以及是否使用交叉驗證。

!!! warning "時間序列資料不能隨機切分"
    預測未來的任務若隨機打散再切分，就會用到「未來的資訊」預測「過去」，造成資料洩漏（data leakage）。時間序列必須按時間順序切分。

### 5.2 評估指標要配合問題類型

| 問題類型 | 常用指標 |
|---|---|
| 分類 | Accuracy、Precision、Recall、F1-score、AUC、混淆矩陣 |
| 迴歸 | RMSE、MAE、MAPE、R² |
| 分群 | 輪廓係數、Davies–Bouldin 指數、群內／群間變異 |
| 排序／推薦 | Precision@K、Recall@K、NDCG、MAP |

!!! warning "類別不平衡時，Accuracy 會嚴重誤導"
    如果真實資料中假評論只佔 5%，一個「全部判為真」的模型就有 95% 的 Accuracy。
    這種情況下應以 **AUC 或 F1** 作為主要判準，並同時報告 Precision 與 Recall，讓讀者看得出模型在少數類別上的表現。

### 5.3 結果分析段落該寫什麼

- 明確說明使用的評估指標與計算方式
- 與基準模型（baseline）的比較，而不只是列出自己的數字
- **模型之間的差異是否具有統計顯著性**（多次執行取平均並報告標準差，或做統計檢定）
- 錯誤分析：挑出典型的誤判案例，分析可能原因
- 不要只列出數字並聲稱「效果更好」

## 六、次級資料與大型資料庫研究

資管研究常使用既有的大型資料庫（政府開放資料、健保資料、平台交易紀錄、公開財報）。這類研究的方法章要特別交代：

- **資料來源與涵蓋期間**、母體與樣本的關係
- **樣本篩選條件**與各步驟的樣本數變化（建議畫流程圖）
- **變數如何從原始欄位建構**出來（這是最容易被質疑的地方）
- **資料庫本身的限制**：哪些欄位不存在、哪些是估計值、有無漏報

### 6.1 傾向分數配對（PSM）

當資料是觀察性的、無法隨機分派時，PSM 是常用的準實驗手段：依據觀察到的共變數估計每個個體「進入處理組」的傾向分數，再把處理組與對照組配對，讓兩組在觀察到的特徵上盡量可比。

**它的限制必須誠實寫出來**：PSM 只能平衡**觀察得到**的共變數，無法處理未觀察到的干擾因子。因此配對後仍不等於隨機實驗。

## 七、資管情境的三個提醒

**提醒一：預測準確率高不等於研究貢獻大。**
把準確率從 91% 提高到 92%，如果沒有理論或方法上的新意，學術貢獻有限。要說清楚「為什麼會更好」，而不只是「確實更好」。

**提醒二：可解釋性在管理情境中是需求，不是加分。**
如果研究的最終使用者是管理者，一個黑箱模型的實務價值會大打折扣。考慮加入特徵重要性分析、SHAP 值或規則抽取。

**提醒三：資料前處理的每一個決定都要交代。**
補值方式、離群值處理、去重規則、文字正規化，都會顯著影響結果，卻最常被省略。它們是可重現性的一部分。

---

## 八、本頁重點回顧

- 演算法 = 如何解題；最佳化 = 如何把結果變好。方法章要分開交代。
- 先確定問題類型（分類／迴歸／分群／最佳化），再選方法。
- Bagging 降變異、不易過擬合；Boosting 降偏誤、可能過擬合。
- 深度學習特徵萃取強，但可解釋性弱、算力需求高。
- **測試集必須完全隔離**；時間序列不能隨機切分。
- 類別不平衡時用 AUC／F1，不要用 Accuracy。
- 一定要有基準線比較，並說明差異是否具統計顯著性。
- 前處理的每一個決定都要寫出來，這是可重現性的一部分。
