# 名詞與用語對照

> 三張表：研究方法名詞的中英對照、統計術語速查、台灣與大陸用語對照。用瀏覽器的 Ctrl/Cmd + F 直接搜尋比較快。

---

## 一、研究設計名詞

| 中文 | 英文 | 一句話說明 |
|---|---|---|
| 研究主題 | research topic | 較寬的領域或議題 |
| 研究問題／論文題目 | research problem / question | 明確到可被嚴謹回答的具體問題 |
| 研究假說 | hypothesis | 研究問題的學術版本，帶方向性的待驗主張 |
| 研究架構 | research framework | 變數關係的圖形化呈現 |
| 問題形塑 | problem formulation | 把現實問題抽象化為學術問題 |
| 概念型定義 | conceptual definition | 這個構念「是什麼」 |
| 操作型定義 | operational definition | 這個構念「怎麼量」 |
| 構念／潛在變項 | construct / latent variable | 無法直接觀察、需透過指標測量的概念 |
| 指標／題項 | indicator / item | 用來測量構念的可觀察項目 |
| 自變項 | independent variable (IV) | 被視為原因或前因的變數 |
| 依變項 | dependent variable (DV) | 被解釋的結果變數 |
| 中介變項 | mediator | 解釋 X 為何影響 Y 的中間機制 |
| 調節變項 | moderator | 改變 X→Y 關係強弱或方向的變數 |
| 控制變項 | control variable | 為排除干擾而納入模型的變數 |
| 干擾因子 | confounding factor | 同時影響 X 與 Y、造成假性相關的第三變數 |
| 反映性指標 | reflective indicator | 構念的表現或結果（構念 → 題項） |
| 形成性指標 | formative indicator | 構成或定義構念的要素（題項 → 構念） |
| 橫斷面研究 | cross-sectional study | 單一時間點的一張快照 |
| 縱貫研究 | longitudinal study | 對同一群對象持續追蹤 |
| 準實驗 | quasi-experiment | 無法隨機分派的實驗設計 |
| 自然實驗 | natural experiment | 利用外生事件造成的分組 |
| 操弄檢核 | manipulation check | 確認受試者確實感受到操弄的差異 |
| 母群體 | population | 研究想推論的全體 |
| 樣本 | sample | 實際被觀察到的一部分 |
| 抽樣框 | sampling frame | 抽樣所依據的名單 |
| 便利抽樣 | convenience sampling | 誰方便就收誰 |
| 滾雪球抽樣 | snowball sampling | 由受訪者轉介受訪者 |
| 立意抽樣 | purposive sampling | 依研究目的刻意挑選 |
| 理論抽樣 | theoretical sampling | 質性研究中為涵蓋理論類型而挑選 |
| 理論飽和 | theoretical saturation | 新資料不再帶來新的概念 |
| 三角驗證 | triangulation | 多來源／多方法／多研究者交叉比對 |
| 厚描述 | thick description | 詳盡到讀者能判斷可否轉移的情境描述 |
| 反身性 | reflexivity | 研究者交代自身立場對研究的可能影響 |
| 人造物 | IT artifact | 設計科學研究產出的構念、模型、方法或系統 |
| 效度 | validity | 有沒有測到該測的東西 |
| 信度 | reliability | 測量結果的一致性與穩定性 |

## 二、統計與分析術語

| 中文 | 英文 | 判準或說明 |
|---|---|---|
| 敘述統計 | descriptive statistics | 平均數、標準差、次數分配 |
| 常態分配 | normal distribution | 鐘形分布 |
| 顯著水準 | significance level | 通常 α = .05 |
| 信賴區間 | confidence interval | 通常報告 95% CI |
| 效果量 | effect size | Cohen's d、η²、f²、β |
| 統計檢力 | statistical power | 建議事前做 power analysis 決定樣本數 |
| 變異數分析 | ANOVA | 比較多組平均數 |
| 共變數分析 | ANCOVA | 控制共變數後比較平均數 |
| 多元迴歸 | multiple regression | 多個自變項預測一個依變項 |
| 邏輯迴歸 | logistic regression | 依變項為類別時使用 |
| 探索性因素分析 | EFA | 尚未確定因素結構時 |
| 驗證性因素分析 | CFA | 已有理論預期的因素結構 |
| 結構方程模型 | SEM | 同時處理測量模型與結構模型 |
| 偏最小平方法 | PLS-SEM | 預測導向、樣本要求較寬鬆 |
| 共變異數基礎 SEM | CB-SEM | 驗證導向、有模型適配檢定 |
| Cronbach's α | — | 內部一致性；≥ .70 |
| 組合信度 | composite reliability, ρ_c / ρ_a | ≥ .70；過高（> .95）可能題項冗餘 |
| 平均變異抽取量 | AVE | ≥ .50 |
| 外部負荷量 | outer loading | ≥ .70 |
| 收斂效度 | convergent validity | 同構念題目彼此相關高 |
| 區辨效度 | discriminant validity | 不同構念界線清楚 |
| HTMT | heterotrait-monotrait ratio | ≤ .85 為佳；> .90 有問題 |
| 變異數膨脹因子 | VIF | ≤ 3 為佳；> 5 有共線性問題 |
| 決定係數 | R² | 模型解釋力 |
| 效果量 f² | f-square | .02 小、.15 中、.35 大 |
| 預測相關性 | Q² / Q²_predict | > 0 表示有預測相關性 |
| 標準化殘差均方根 | SRMR | 常見門檻 < .08 |
| 自助法 | bootstrapping | 用於檢定路徑係數與間接效果的顯著性 |
| 中介效果 | mediation effect | 報告間接效果係數與 95% CI |
| 多群組分析 | MGA | 比較不同群組的路徑係數 |
| 測量不變性 | MICOM / measurement invariance | 跑 MGA 前必做 |
| 共同方法變異 | CMV / CMB | 同一方法造成的系統性誤差 |
| 傾向分數配對 | PSM | 觀察性資料的準實驗配對手段 |
| 過度擬合 | overfitting | 模型記住了訓練資料的雜訊 |
| 訓練／驗證／測試集 | train / validation / test | 測試集必須完全隔離 |
| 精確率 | precision | 預測為正的當中，真的是正的比例 |
| 召回率 | recall | 實際為正的當中，被抓出來的比例 |
| F1 分數 | F1-score | 精確率與召回率的調和平均 |
| 曲線下面積 | AUC | 類別不平衡時比 Accuracy 可靠 |
| 梯度下降 | gradient descent | 最基本的參數最佳化方法 |
| 學習率 | learning rate | 梯度下降中最關鍵的超參數 |
| 遺傳演算法 | genetic algorithm | 啟發式最佳化，適合組合問題 |
