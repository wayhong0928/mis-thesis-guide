# 論文架構與各章寫作要領

> 論文寫作本質上是一場攻防戰。你不只要讓讀者相信這個研究的成果，還要預先設想他們可能的質疑，把自己的主張防衛得滴水不漏。

---

## 一、六個主要部分與它們的分工

不管是哪個學術領域、量化或質性、學位論文或期刊論文，以實證研究為基礎的論文通常包含六個部分：

```
摘要 → 導論／緒論（含問題背景與文獻回顧）→ 理論依據、研究方法與架構
     → 結果、分析與討論 → 結論與未來研究建議 → 參考文獻
```

這六個部分內容或許有些重疊，但**各有明確的功能與角色，且彼此相銜、前後呼應**。如果只是依樣畫葫蘆抄襲主題相近的論文架構，很容易畫虎不成反類犬。

| 部分 | 核心功能 | 常見失誤 |
|---|---|---|
| 摘要 | 像廣告文宣，也像一張必須兌現的支票 | 平淡無奇看不出特色；或誇大到論文兌現不了 |
| 導論／緒論 | 說服讀者這個主題重要，且本研究有必要 | 文獻篇幅蓋過本研究自身的主張；或把研究情境寫太死 |
| 文獻探討 | 描繪知識邊緣、釐清本研究與文獻的關係 | 只敘不評的流水帳 |
| 理論與方法 | 論證「為何這麼做」，並讓人能複製 | 只寫怎麼做，不寫為什麼 |
| 結果與討論 | 呈現證據，逐步論證到最終結論 | 證據到哪裡，結論跳到更遠 |
| 結論 | 客觀總結貢獻與限制 | 複製貼上導論；或誇大貢獻 |

## 二、寫作次序：不要照著章節順序寫

**建議的順序**：

```
① 導論初稿（粗略）
   ↓
② 理論依據與研究方法
   ↓
③ 結果與討論
   ↓
④ 回頭細修導論並定稿
   ↓
⑤ 最後才寫結論
   ↓
⑥ 最後的最後才寫摘要
```

理由很簡單：

- 摘要的字數最少、篇幅限制最嚴苛，因而是**最難寫的部分**。
- 只有當方法與結果都寫完，你才確知這個研究有哪些可靠的成果與特色，回頭改導論時思緒才會清晰、下筆才會篤定。
- 導論定稿之後，整篇文章的重點與精華已經徹底釐清且濃縮過，這時候寫摘要才容易掌握。

!!! note "質性研究的寫作是另一回事"
    社會學的寫作經常涉及極為複雜的概念與事實，「成竹在胸、一氣呵成」的模式並不適用。
    **寫作是釐清思緒的唯一方法，唯有一再改寫才能逐漸釐清思緒**，並同步摸索出論文的適當架構與內容的最佳剪裁。

### 2.1 寫作的最小可交付單位

寫作次序解決「先寫哪一章」，但多數人卡住的其實是**每天要交出什麼**。

「今天要寫第二章」是一個沒辦法完成、也沒辦法宣告完成的目標，所以它每天都會被延後。把它換成**最小可交付單位**：

> ❌ 今天寫第二章
> ✅ 今天把 ⟨某個構念⟩ 那一節的論證鏈寫完（約 400–600 字，三層結構跑完一輪）

一個好的最小單位有三個特徵：**一到兩小時做得完**、**做完看得出來**、**可以直接貼進論文**。

三個配套習慣：

- **用純文字起草，最後才轉排版。** Markdown 或任何純文字工具都行；在 Word 裡邊寫邊調格式，會讓你把注意力花在錯的地方。
- **給指導教授看之前先大聲唸一遍。** 中文學術寫作的流暢度問題，用眼睛看很難抓；唸出來卡住的地方，通常就需要修改。
- **引用格式從第一天就管好。** 「之後再整理」的代價是最後一週重排一百多筆參考文獻，而且一定會出錯。做法見[文獻管理與知識庫](tools-knowledge.md)。

!!! tip "計畫書就是初稿的骨架"
    如果你已經寫過研究計畫書，論文不是從零開始：計畫書的研究背景與問題 → 第一章；文獻整合 → 第二章（**每一節從「這篇文獻能幫我說什麼」出發擴充論證，不是堆砌摘要**）；假說與模型圖 → 第三章核心，補上操作型定義、抽樣設計、資料蒐集流程與分析步驟；量表 → 附錄。
    把計畫書各節對應到論文各節，你會發現剩下的是**擴充**，不是創作。

### 2.2 從 Markdown 組裝成 Word 計畫書

純文字適合起草，Word 適合套用系所格式、插入即時引用並完成目錄。組裝時以**你的系所論文範本**為底稿，先確認封面、頁首頁尾、行距與頁碼規則，再把各章內容貼入對應位置。

| Word 章節 | 常見來源檔 |
|---|---|
| 摘要／Abstract | `Ch0_摘要.md` |
| 第壹章 緒論 | `Ch1_緒論.md` |
| 第貳章 文獻探討 | `Ch2_文獻探討.md`，或依主題拆成數個子節檔 |
| 第參章 研究方法 | `Ch3_研究方法.md` |
| 第肆章 預期貢獻與研究限制 | `Ch4_預期貢獻與研究限制.md` |
| 參考文獻 | 由 Zotero 依全文引用自動產生 |

檔名只是通用慣例，可以依個人工作方式調整。真正需要固定的是章節對應關係與版本來源，避免同一節在多個檔案各有一份。

#### 貼入與套用樣式

1. 以系所範本新建 Word 檔，保留既有的版面與分節設定。
2. 依章節順序貼入 Markdown 內容。章、節、小節分別套用 Word 的「標題 1」「標題 2」「標題 3」，一般段落套用內文樣式，不要逐段手調字型與間距。
3. Markdown 表格貼入後，使用 Word 的「文字轉換成表格」或重新插入表格，再套用一致的表格樣式。

#### 引用與參考文獻

1. 安裝 Zotero 桌面版與 Word 外掛，並依系所要求選擇引用樣式；採 APA 第七版時，再核對系所對中文文獻的細部規定。
2. 把草稿中的每一筆「（作者, 年份）」佔位文字，就地替換成 Zotero 即時引用。插入前要確認作者、年份、題名與來源無誤。
3. 全文引用完成後，在參考文獻章節使用 Zotero 的插入書目功能，統一產生全文書目。各節末若留有工作用參考清單，組裝時應刪除，避免重複與格式不一。

!!! warning "書目資料只維護一個來源"
    若先前以 BibTeX 或 `.bib` 檔管理引用，切換到 Zotero 後不要同時手動維護兩套書目。先確認哪一套是唯一來源，再從該處更新與匯出，否則作者、年份或題名很容易出現版本差異。文獻庫整理方式見[文獻管理與知識庫](tools-knowledge.md)。

#### 圖表、目錄與定稿

- 圖放在正文第一次提及之後，圖說置於圖下；表題置於表上。圖表位置與標示仍以系所範本為準。
- 使用 Word 的標號功能管理圖號與表號，再由「插入圖表目錄」產生圖目錄與表目錄。正文標題全部套好樣式後，再插入自動目錄。
- 補齊封面、頁碼、頁首、附錄與其他系所要求的前後置項目；誌謝是否需要放入計畫書，先查系所規定。
- 定稿前核對全文反覆出現的關鍵數字，例如樣本數、量表題項數、假說數與構念數量。任何一處修改後，都要全文搜尋同一數字與相關敘述，確認方法章、結果章、摘要、圖表及附錄同步更新。

最後更新全部目錄、交叉參照與 Zotero 欄位，另存 PDF 檢查分頁、圖表位置與字型是否跑掉，再交付正式版本。

## 三、下筆前的三個準備動作

### 3.1 盤點研究成果，選定論述重點

《孫子兵法》說「勝兵先勝而後求戰」。論文寫作也是如此：**先營造有利於自己的形勢，等到立於不敗之地，才開始作戰。**

具體作法：

1. 遴選一個學術界既存的觀點、主張或方法，作為你準備要挑戰或補足的對手
2. 盤點自己的證據與論證，看是否足以在某個適用範圍內駁倒或補足它
3. 同時盤點**有利於對方**的文獻與證據，揣想對方可能會如何答辯
4. 確定自己有十足勝算時，再把這些攻防的盤算整理成論述策略與論文架構

**兩大好處**：聚焦明確，容易突顯重要發現；焦點越明確，越有機會論證得深入且嚴謹。反之，議題與範圍太寬泛，容易讓讀者失焦，也容易流於泛論。

!!! warning "定位錯誤的代價"
    一篇後來成為社會學經典的論文，第一次投稿時被直接退稿，因為作者把它包裝成對某個既有理論的再探討，而評審認定他誤解了那個理論。
    他把該理論的討論全數移除、徹底聚焦在自己真正的貢獻上之後，論文被頂尖期刊接受。
    **研究成果即使富有原創性，定位錯誤仍可能使評審無法看見貢獻；重新定位也可能讓原本不突出的成果獲得較合適的解讀。**

### 3.2 建立論證的層次架構

把主要結論與研究發現逐一寫下來，先不管輕重與先後。接著分析它們之間的內在邏輯關係：

```
證據 ─┐
證據 ─┼→ 小結論 ─┐
證據 ─┘           ├→ 中間層次結論 ─┐
證據 ─→ 小結論 ─┘                  ├→ 最終結論
證據 ────────────────────────────────┘
```

一邊釐清結論之間的關係，一邊自問：**你是依據哪些證據和論證過程獲得這些結論的？** 可以為每一個小結論與中間結論各建一個檔案，摘要寫下它所憑據的證據、假設（條件與適用範圍）與主要論證過程。

### 3.3 挑三到五篇最接近的近期論文當參考

理由有三：

1. 用它們合併起來覆蓋「本研究最鄰近的既有文獻邊界」，就能斷定你確屬原創的部分
2. 從中彙整對其他理論、方法、證據的批判，同時用來為自己的選擇辯護
3. 主題、範圍與方法相近時，論文結構與章節次序也會有許多雷同處，可供參考

## 四、緒論／導論的寫作要領

!!! note "想看更完整的版本"
    這一節的三功能框架，對應到 Swales (1990) 提出的 **CARS model**（Create A Research Space，見 4.1）。坊間論文寫作指南對這個框架多有更完整的示範，本站只做通則式的重述（延伸資源見[延伸閱讀與資源指南](sources.md)第二節與第四節）。

導論必須承載三大任務，對應到 CARS model 的三個 move：

1. **建立領域（establishing a territory）**：介紹研究主題、背景及其在學術與應用上的重要性，讓讀者相信它值得被研究。
2. **建立利基（establishing a niche）**：回顧學術界過去的研究，扼要評價得失，指出至今仍待解決的部分，並明確說明本研究如何跟既有文獻區隔、如何填補不足。
3. **佔據利基（occupying the niche）**：扼要敘述本研究擬採用的觀點、理論、方法與資料來源，以及它們相對於既有文獻的優點。

有些作者還會加上兩個功能：預告主要研究成果，以及簡介後續章節的內容與次序——這兩項對應下方 move 3 底下的延伸步驟。

> **方法論依據**：Swales, J. M. (1990). *Genre Analysis: English in Academic and Research Settings*. Cambridge University Press. 提出的 CARS（Create A Research Space）model 主張，學術論文導論依序完成三個 move 才算完整。獨立公開整理見 Wikipedia〈CARS model〉<https://en.wikipedia.org/wiki/CARS_model> 與 USC Libraries〈The C.A.R.S. Model〉<https://libguides.usc.edu/writingguide/CARS>（查證日期 2026-09-06）。

### 4.1 CARS model 三個 move 的具體步驟

| Move | 功能 | 典型步驟 |
|---|---|---|
| ① 建立領域 | 說服讀者這個主題重要 | 主張主題的核心性、對現況做出概括性陳述、回顧既有研究 |
| ② 建立利基 | 指出研究空間 | 反駁既有主張、指出知識缺口、提出未解決的問題、延續既有研究傳統的下一步——擇一或組合使用 |
| ③ 佔據利基 | 宣告本研究的貢獻 | 說明研究目的、宣告研究方向、預告主要發現、說明後續章節結構 |

### 4.2 兩個關鍵紀律

**紀律一：檢視既有文獻的不足時，要聚焦在跟本研究貢獻相關的部分**，而不是長篇大論臚列一堆本研究也無法解決的問題。

**紀律二：導論的主角只有兩個**，也就是研究主題的意義與價值，以及本研究在觀點、理論、證據與方法上的創新。既有文獻是佐證用的配角，篇幅不該蓋過主角。

!!! warning "第一印象決定大半評價"
    研究顯示，很多審查委員在讀完摘要與導論之後就已經對論文有初步評價，而這個第一印象跟讀完全文後的評價常常相去不遠。
    如果導論遺漏重要文獻，表示見識淺薄；論述雜亂無章，表示囫圇吞棗；只是流水帳臚列而沒有一針見血的得失評價，表示欠缺洞見與批判力。

## 五、理論依據與研究方法

要先分清楚兩件事：

- **研究方法（research method）**：描述你**如何（how）**做，包括產出研究結果的方法、程序與步驟。
- **理論依據與方法論的考量（methodology）**：論證你**為何（why）**這麼做，提出充分理由，把你的方法、策略與研究架構合理化。

> **方法論依據**：method 描述「怎麼做」、methodology 論證「為何這麼做」的區分，是研究方法教學的標準內容。獨立公開來源：Enago,〈Difference Between Research Methodology and Methods〉<https://www.enago.com/academy/difference-methods-and-methodology/>；CASRAI,〈Method vs. Methodology〉<https://casrai.org/guides/method-vs-methodology>（查證日期 2026-09-06）。

### 5.1 方法章的兩個任務

**任務一：讓人能複製。**
必須清晰交代整個研究的方法與步驟，讓同領域的專家能據以複製出相同的結果。這份清單的分類架構參考 APA Journal Article Reporting Standards（JARS-Quant）對量化研究方法章應報告項目的整理（見下方引註），至少要交代：

- **參與者／資料特性與抽樣程序**（樣本來源、招募或篩選方式、樣本數如何決定）
- **測量工具與變項操作化**（量表、儀器、設備、編碼方式）
- **研究設計與情境**（施測或採樣時間，以及觀察地點、環境或訪談情境）
- **資料的後處理與數據化程序**（清理規則、不當資料的剔除、逐字稿編碼）
- **資料分析策略**（統計方法、軟體、參數設定、分析步驟）

> **方法論依據**：以上分類參考 APA,〈Journal Article Reporting Standards〉<https://www.apa.org/pubs/journals/resources/apa-style-jars.html> 與 APA Style,〈Quantitative research design (JARS–Quant)〉<https://apastyle.apa.org/jars/quantitative>（查證日期 2026-09-06），僅取其分類架構，實際條目請以原文件為準。

**任務二：預先回應可能的質疑。**
方法章不能只有敘述，還要有客觀的自我檢視。一邊敘述「我們這麼做」，一邊說明「為什麼這麼做、為什麼不採其他替代方案、有哪些潛在疑慮、為什麼它們不會影響主要結論」。

### 5.2 可重複性與可讀性的平衡

在追求可重複性的同時，必須維持論文的可讀性。原則是：

- 對結果有**重大影響**的程序、步驟和數據 → 詳細寫
- 既有的標準處理程序或資料庫 → 引註參考文獻即可
- 次要的敘述 → 放到附錄
- 過分瑣碎、有礙思緒的細節 → 捨棄

這些取捨往往反映作者對研究主題的專業判斷能力。**下筆前找三五篇主題與方法都相近的論文參考**，斟酌哪些可以簡略、哪些必須詳述。

## 六、結果與討論

「結果的分析與討論」與「研究的方法與步驟」在結構上前後相銜，在論證上必須緊密扣合。

### 6.1 一個重要的紀律

> **證據顯示到哪裡，推論就進展到哪裡，絕不在證據不足時跳躍地妄下結論。**

這是不分學科與研究類型都必須恪守的軌範。

### 6.2 結果章的內部結構

它雖然只是一個章節，內部結構卻十足是一篇小論文：

1. 呈現主要的結果（證據）
2. 跟既有文獻的發現相連結或比較異同
3. 根據這些證據進行分析與論證，逐步導向最終結論
4. 過程中同時說明各項發現的得失、意義與價值，並預先回應可能的質疑

### 6.3 沒有明確結論的發現怎麼處理

研究過程往往會出現未曾預料的線索、證據或疑點，而且無法在結案時充分釐清。處理方式：

1. 把它們跟成熟的結論**明確區分開來**
2. 先描述、分析、論證可以有確切結論的結果
3. 之後才擇要報告無法做出確切結論的發現與疑點
4. 評估它們潛在的意義與價值，以及對本研究結論可能的影響
5. 建議未來研究如何加以釐清或改善

!!! warning "不要隱瞞缺點或過度防衛"
    在學術界會被視為「欠缺客觀衡量個人研究成果的能力」，等於暴露學術能力的不足。
    論文只需要有適當的貢獻，不需要完美無瑕。**「誠實」是科學與學術研究的第一守則。**

### 6.4 比較基準的選擇

數據的真實意義，往往只有在恰當的比較基準下才會正確顯露出來。一旦比較基準不當，意義就會被扭曲。

三個常見的陷阱：

1. **絕對值 vs 相對值**：兩個國家的確診人數，總人口相差五倍時就不能直接比。應改用「每百萬人口」。
2. **量測誤差與平滑化**：只挑最高點那一天的數據來比較，很容易被通報延遲等量測誤差誤導。學術界往往先做移動平均再比較。
3. **衡量指標與直覺不符**：一個「概念模糊、跟直覺概念有遙遠距離」的指標，很容易傳遞錯誤訊息，讓人得出相反的結論。

**當研究主題牽涉的因素越複雜，比較基準也必須相對夠複雜、周延，才能得出合理的結論。** 若無法窮盡所有因素，就明確宣告「在不考慮其他因素的影響下」進行研究與結論。

### 6.5 資料視覺化

設計得當的圖表是突破難題的關鍵利器；設計不當時，也可能成為誤導讀者的亂源。

**必備元素**（很多碩論初稿都缺）：

- 圖表**編號與名稱**
- 橫軸與縱軸的**變數名稱、單位與尺規**（線性、對數或半對數）
- 每一條曲線的**屬性標示**、每一欄位的**名稱與單位**
- 正文中對圖表關鍵內容的**提示、補充說明與評論**

!!! tip "選對座標軸的變數，訊息才會浮現"
    一張比較兩百多年來小麥價格與工資變化的經典圖表，因為縱軸變數選得不好，看不出作者想傳遞的訊息。
    把縱軸改成「購買固定份量小麥所需的工時」之後，「實質工資大幅提升」這個結論就一目了然。
    **同一組數據，換一個縱軸就換一個故事。** 這是視覺化最重要的一課。

一個常見的碩論疏漏：把圖表丟進論文卻不在正文中引導。一張圖表的資訊極其豐富，**沒有作者的文字引導，讀者不可能知道你想表達什麼。**

### 6.6 案例的選擇與排序

「代表性」通常指下列幾種之一：

- 介於最常見與最極端的數種案例
- 介於最有利與最不利的數種案例
- 介於結論最明確與最不明確的數種案例

排序策略：**由簡而繁**（先比較假設較單純、容易說明的案例，再慢慢增加複雜度），或**由不利到有利**（先證明「即便在無法發揮本方法優勢的情境下依然略勝一籌」，再用最貼近實際應用的情境證明大幅領先）。

---

## 七、摘要

摘要必須在極短篇幅內依序交代五個重點：

1. 研究的**主題**
2. 既有文獻的**關鍵缺失或不足**（等於本文企圖解決的課題）
3. 本研究所採用的**方法**
4. 最關鍵、最吸引人的**研究成果**
5. 精簡的**結論**

**措詞必須直白、句句精要、直指核心**，完全沒有花俏修辭的空間，更容不下廢話。

它同時是廣告文宣，也是一張必須立即兌現的支票：

- 太平淡 → 讀者懷疑這篇論文乏善可陳
- 過度誇大 → 作者有不誠實的嫌疑，或嚴重欠缺客觀評價研究成果的能力

**開始下筆前，拿出跟本研究最相近的論文當參考，看看它們的摘要是如何架構與措詞的。**

---

## 八、結論

一篇論文的結論通常比導論短、比摘要略長，且分成數段。

**結構**：

1. 精簡重提研究主題與方法，扼要總結主要發現和結論
   （內容在導論已提過，但語氣從「預期的結果」變成「確實的結果」，不應該只是複製貼上）
2. 扼要說明這些發現對學術界或產業界的主要貢獻
   （像**簡答題**而不是申論題。若擔心太簡潔不足以讓讀者明白貢獻，該補充的是**導論**與**結果與討論**，而不是結論）
3. 扼要指出研究的主要限制、適用範圍與不足處，並建議未來如何擴充、發展與改善

**最重要的要領**：儘管結論是在檢討自己的貢獻與不足，**行文語氣必須像是公正的第三者**。對自己的貢獻既不誇大也無須謙詞，對缺失無須迴避也沒必要語帶歉意。

!!! note "研究限制寫得深刻，是加分項"
    學位論文不宜省略研究限制，因為這是你表現批判性思考與專業成熟度的另一個機會。
    寫得深刻而有見地，會有加分的效果；寫得敷衍（「本研究樣本數較少」然後就沒了），反而暴露你沒認真想過。

## 九、台灣碩論的章節慣例

```
第壹章　緒論
  第一節　研究背景與動機
  第二節　研究目的與問題
  第三節　名詞釋義（有些系所放在第三章）
  第四節　研究流程（或研究範圍與限制）

第貳章　文獻探討
  第一節　XX 理論與相關研究（節末點出本節的缺口）
  第二節　XX 理論與相關研究（節末點出本節的缺口）
  …

第參章　研究方法（或研究設計與實施）
  第一節　研究架構（含架構圖）
  第二節　研究假說
  第三節　操作型定義與測量工具
  第四節　研究對象與抽樣方式
  第五節　資料分析方法

第肆章　研究結果與討論（或分成兩章）
  第一節　敘述統計
  第二節　測量模型評估
  第三節　結構模型分析
  第四節　假說驗證結果

第伍章　結論與建議
  第一節　研究結論
  第二節　理論貢獻
  第三節　實務貢獻（或管理意涵）
  第四節　研究限制
  第五節　未來研究方向
```

**注意事項**：

- 章用國字大寫（壹貳參肆伍），節用一般中文數字（一二三四五）
- 用「**文獻探討**」，不用「文獻回顧」或「文獻綜述」（後者偏大陸用法）
- 台灣碩論的文獻探討章**通常不會在整章最後獨立寫一節「研究缺口」來總結**；研究缺口的陳述要分散在各小節結尾點出（每節談完一批文獻，就在該節末段交代這節留下什麼缺口），見[文獻回顧與批判性思考](literature.md) §5.3、§5.4 的三層結構與四步論證鏈
- 用「**研究方法**」，不用「研究方法論」（methodology 的層次留給博士論文討論）
- 研究方法章**通常不會另闢一節處理研究倫理或 AI 揭露**；這類內容多半整合進送審流程或獨立聲明頁，對應[學術倫理與 AI 揭露](ethics.md)，不代表它必然是研究方法章固定的某一節
- 計畫書（proposal）通常只寫到第參章，加上預期貢獻與研究限制

### 9.1 各章的參考頁數（碩論）

| 章節 | 建議篇幅 | 說明 |
|---|---|---|
| 研究背景與動機 | 5–10 頁 | 要講清楚研究問題的重要性 |
| 文獻探討 | 15–20 頁 | 要有最近五年文獻，管理類建議做比較表 |
| 研究方法與設計 | 10–15 頁 | 架構、假說、操作型定義、抽樣、分析方法 |

（實際頁數依系所與指導教授要求調整，此處僅為常見的參考值。）

## 十、論文的完整樣貌與裝訂次序

國內大學常見的規定順序：

```
封面 → 口試委員審定書 → 致謝辭（非必要）
→ 中文摘要及關鍵詞 → 英文摘要及關鍵詞
→ 正文目次 → 插圖目次 → 表格目次
→ 論文正文 → 參考文獻 → 附錄（非必要）→ 封底
```

**實際格式一律以所屬系所的規定為準。**

### 10.1 參考文獻清單的態度問題

學位論文篇幅可觀，錯別字往往難免，多數口試委員也較能寬容。但**參考文獻清單通常只有數頁**，如果連這幾頁都無法仔細訂正，往往會被認定為態度草率。

口試委員常做的檢查：隨機挑幾則參考文獻，確認正文中的引註與文末清單確實吻合，而且格式前後統一，包括標點符號的正確性、位置，以及標點後是否有空白格。

### 10.2 致謝辭與共同作者

該被感謝的對象包括：對論文品質有直接助益的師長、提供儀器設備或環境的單位、協助發放問卷與編碼的學弟妹、口試委員、獎學金提供者。

若是共同掛名，國際上較務實的三項要件是：

1. 對論文有**重大貢獻**（研究構想與設計，或資料的擷取、分析與詮釋，或撰寫與重大改寫）
2. **仔細讀過完稿全文**並同意其出版
3. 對自己的貢獻**負責**，並確保跟個人貢獻無關的部分也已被其他人適當處理

有貢獻但無法滿足這三項的（提供經費、場地、設備、被動諮詢），只適合列名於致謝辭中。

## 十一、措詞：「寄出」與「送達」的差別

一封平信只能叫「寄出」（send），因為對方不一定收到；掛號並確知對方收到，才叫「送達」（deliver）。

**如果使用者手冊中的訊息讓許多讀者讀不懂，這份手冊就沒有「送達」訊息。這是誰的錯？當然是撰稿者的錯。**

同樣的，如果論文有任何措詞、段落讓學長姊讀不懂，或覺得論述太牽強、薄弱，就必須修改到他們能理解、認同，才算達成最起碼的任務。

**改善辦法**：

- 寫完初稿後反覆重讀，揣摩讀者可能的反應，改到順口為止
- 請學長姊幫忙讀，請他們挑出讀起來不順或不夠清晰的地方，並講出自己的理解
- 句子太糾纏時，把裡面的概念**分解**成幾個簡單句子，再用最後一句整合
- 有時候只要**調換次序**，把單純易懂的放前面，把引用前述思想的放後面，文句與思路就會同時通暢

---

## 十二、本頁重點回顧

- 論文六大部分各有功能，彼此呼應，不能依樣畫葫蘆。
- 寫作次序：導論初稿 → 方法 → 結果 → 回頭修導論 → 結論 → 摘要。
- 下筆前先選定論述重點、建立論證層次、挑三五篇最近的參考論文。
- 導論的主角是研究的價值與本研究的創新；文獻是配角。
- 方法章要能被複製，也要預先回應可能的質疑。
- **證據到哪裡，推論就到哪裡。** 誠實是第一守則。
- 比較基準與座標軸的選擇會決定數據講出什麼故事。
- 摘要是廣告也是支票；結論的語氣要像公正的第三者。
- 研究限制寫得深刻是加分項；參考文獻的格式是態度問題。
- 論文要「送達」而不只是「寄出」。
