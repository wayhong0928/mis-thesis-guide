# 量化分析規劃與資料處理基礎

> 從研究問題、分析計畫與資料字典開始，把原始資料轉成可檢查、可重跑、能支持適當主張的分析結果。

---

## 一、分析不從開軟體開始

統計軟體可以很快算出係數，卻不會替研究者判斷分析單位、測量尺度、抽樣方式與模型是否相配。資料進軟體前，先把問題寫成一條可檢查的推理：

> 研究問題 → 理論構念 → 操作型定義 → 資料來源與分析單位 → 統計方法 → 可支持的結論

任何一段接不上，都應先回頭修正。若研究問題問的是個人行為，資料列卻代表帳號或交易事件，係數再精確也可能答非所問。

!!! note "描述、比較、相關與因果要分開"
    描述資料分布、比較群組、估計變數關係與識別因果效果，需要不同設計與假設。橫斷觀察資料通常支持相關或預測，不會因為使用複雜模型就自動取得因果解釋。

---

## 二、先寫分析計畫

分析計畫的目的，是把研究者的自由度攤開來。至少寫清楚：

- 研究問題、假說與主要／次要結果變項
- 分析單位、母體、樣本來源與納入條件
- 每個構念或變項的計算方式
- 主要模型、比較基準與調整變項
- 分組、中介、調節或重複量測的處理
- 遺漏值、異常值與資料排除規則
- 模型假設及不符合時的替代方案
- 穩健性或敏感度分析
- 圖表、效果估計、不確定性與報告方式

計畫不是不能改。探索時發現資料結構與原先理解不同，修改很正常；但要記錄何時改、為什麼改，並區分事先規劃與事後探索。這讓讀者知道哪些檢定是原問題的回答，哪些是新線索。

### 2.1 從問題選方法

| 研究目的 | 要先確認 | 可能的分析家族 |
|---|---|---|
| 描述分布與趨勢 | 變項型態、時間與權重 | 次數、比例、集中與離散、圖表 |
| 比較群組 | 群組形成、基準差異、相依性 | 平均或分布比較、迴歸、配對方法 |
| 估計關係或預測 | 結果型態、函數形式、過度擬合 | 相關、廣義線性模型、預測模型 |
| 檢驗潛在構念關係 | 測量模型、樣本與識別條件 | 因素分析、SEM／PLS-SEM |
| 分析重複或群聚資料 | 個體、班級、組織或時間內相依 | 混合模型、群聚穩健方法、縱貫模型 |

表格只指出方向。實際模型還要依研究設計、分布、樣本資訊量及領域慣例決定，不宜把某種檢定視為所有連續或類別資料的固定答案。

---

## 三、資料字典是分析的地基

資料字典讓欄位的意義與處理規則不依賴記憶。最低限度可用下列欄位：

| 欄位 | 說明 |
|---|---|
| 原始變項名 | 資料來源中的欄位名稱 |
| 分析變項名 | 程式碼與報告採用的名稱 |
| 定義與分析單位 | 測量什麼，每列或每筆代表什麼 |
| 型態與尺度 | 文字、日期、名目、次序、計數或連續 |
| 合法值與單位 | 可接受範圍、類別代碼、時間或貨幣單位 |
| 缺失碼 | 空白、NA、拒答、不適用或系統遺漏如何區分 |
| 來源與版本 | 問卷題號、系統表、資料庫版本或下載日期 |
| 轉換規則 | 反向計分、加總、標準化、分組或合併方式 |
| 使用角色 | 主要結果、預測變項、控制變項、識別碼或權重 |

!!! warning "0 不一定是零"
    有些資料以 0、9、99 或負值表示未填、拒答與不適用。如果沒讀代碼表，這些值會被當成真實觀察值參與平均與模型估計。先還原語意，再轉成分析用缺失碼。

### 3.1 保留資料來歷

每份原始檔記下來源、取得日期、版本、授權與校驗資訊。跨表合併時，記錄鍵值、配對成功率、一對多關係與未配對原因。更多既有資料的判讀方式見[次級資料分析與檔案研究](method-secondary-data.md)。

---

## 四、建立不覆寫原始資料的流程

原始資料設為只讀。所有更正、轉碼、排除與衍生欄位都在程式碼或轉換日誌中完成，產生新的中間檔與分析檔。

```text
project/
├── data_raw/        原始輸出，只讀
├── data_clean/      可由程式重新產生
├── scripts/         依執行順序編號
├── output/          表格、圖與模型輸出
├── docs/            資料字典、分析計畫、決策日誌
└── README.md        執行環境、順序與必要說明
```

檔名使用固定規則，日期採不易混淆的格式。不要以 `final_final2.xlsx` 管理版本，也不要手動修改輸出表後忘了同步分析程式。

### 4.1 每一步都要有筆數核對

資料匯入、合併、篩選、轉長寬格式與排除後，記錄列數、唯一個體數、重複數及關鍵欄位遺漏數。若筆數意外增加或減少，先查明原因再往下跑。

---

## 五、資料清理的合理順序

### 5.1 結構與型態

- 檢查編碼、欄名、日期格式、小數點與單位
- 確認每列、每欄與每張表代表的實體
- 找出完全重複與鍵值重複，判斷是錯誤還是合理的重複量測
- 檢查類別拼字、前後空白與大小寫造成的假類別

### 5.2 邏輯與範圍

- 驗證不可能值，例如結束日在開始日前、比例超出定義範圍
- 檢查跳題邏輯與互斥欄位
- 對照原始系統或問卷，區分輸入錯誤與真實極端觀察
- 確認反向題與量尺方向，不要只靠欄名猜測

### 5.3 衍生變項

衍生變項要在資料字典記公式、條件、單位與缺失值傳遞規則。分數、分類與時間窗若有多種合理定義，可在分析計畫指定主要版本，其他版本用於敏感度分析。

!!! tip "先畫圖再看單一統計值"
    次數表、直方圖、箱形圖、散布圖與時間序列圖能揭露錯碼、群聚、天花板效應、非線性與制度斷點。圖形用來診斷資料，不是分析完成後才補的裝飾。

---

## 六、遺漏值不能只按一個刪除鍵

先分清楚遺漏的來源：未作答、拒答、不適用、追蹤流失、系統故障、資料串接失敗，或原設計根本沒有收。這些情況的含義不同，不應全部併成同一個空白。

### 6.1 先做遺漏概況

至少報告每個變項的遺漏數與比例、每筆資料的遺漏程度、共同遺漏模式，以及遺漏與可觀察特徵的關係。若某群人更容易缺資料，完整案例分析可能改變樣本組成。

### 6.2 處理方式要說明假設

| 做法 | 何時可能考慮 | 主要風險 |
|---|---|---|
| 完整案例分析 | 遺漏有限，且其機制與目標分析可合理相容 | 浪費資訊，樣本可能偏移 |
| 單一插補 | 特定描述或流程需要完整欄位 | 常低估不確定性，不宜把填補值當真值 |
| 多重插補 | 模型與可用變項足以支持插補模型 | 需正確指定模型並合併估計不確定性 |
| 模型式處理 | 所用模型能在明確假設下使用不完整資料 | 假設不合理時仍會偏誤 |
| 權重或敏感度分析 | 追蹤流失、選擇進入分析等問題 | 權重模型與未觀察機制仍需論證 |

不能用單一遺漏比例門檻決定方法。處理方式取決於遺漏機制、變項角色、模型與研究問題；主分析之外，應評估不同合理處理是否改變結論。

---

## 七、離群值與影響點要查原因

離群值是相對於資料分布或模型顯得異常的觀察；影響點則會明顯改變估計結果。兩者不是「錯誤值」的同義詞。

檢查可分三層：

- **資料層**：輸入、單位、串接或感測錯誤
- **現象層**：少見但真實的個案、特殊群體或制度事件
- **模型層**：非線性、長尾分布、異質群體或模型設定不當

箱形圖界線、標準化距離與各種影響度量只是標記候選值，適用性取決於分布及模型。沒有一個數值能跨所有資料自動決定刪除。

!!! danger "不得為了顯著而刪離群值"
    只有能證明資料錯誤、違反事先納入規則或屬於不同分析母體時，刪除才有明確依據。真實但極端的值可採轉換、穩健方法、分層模型或敏感度分析，並同時報告處理前後結果。

---

## 八、假設檢查要對準模型

「資料常態」不是所有方法的通用前提。許多模型關心的是條件分布或殘差，類別與計數模型也有自己的分布與結構假設。先問模型依賴什麼，再選診斷工具。

### 8.1 常見檢查面向

| 面向 | 可用診斷 | 不符合時可能處理 |
|---|---|---|
| 觀察值獨立或相依結構 | 研究設計、群聚／時間圖、相關結構 | 混合模型、群聚穩健估計、時間序列方法 |
| 函數形式與線性 | 散布圖、殘差對擬合值、部分殘差 | 轉換、非線性項、分段或其他模型 |
| 變異是否穩定 | 殘差圖、依群組比較 | 異質變異模型、穩健標準誤 |
| 分布假設 | 直方圖、分位數圖、殘差診斷 | 改用合適分布、穩健或無母數方法 |
| 共線性 | 變項關係、條件指標或 VIF 等 | 回到理論刪整冗餘、重新參數化 |
| 高影響觀察 | 殘差、槓桿值與影響度量 | 查資料、報告敏感度、採穩健方法 |

正式檢定會受樣本數影響，大樣本可能把細微偏離判為顯著，小樣本又可能沒有能力發現問題。因此圖形、設計知識、效果大小與檢定結果應一起判讀。

### 8.2 假設不符不是自動換檢定

先確認問題來自資料錯誤、模型形式、群聚、分布，還是研究設計。每種替代方法也有自己的假設。報告時說明檢查了什麼、發現什麼、採取何種處理，以及結論對處理方式是否敏感。

## 九、估計、檢定與報告

p 值只回答在特定模型與虛無假設下，觀察到目前或更極端資料的相容程度。它不表示效果大小、理論重要性、結果可重現的機率，也不能單獨判斷研究價值。

分析結果至少搭配：

- 樣本與排除流程
- 描述統計與適當圖形
- 效果估計及其不確定性，例如信賴區間
- 模型設定、調整變項與假設診斷
- 多重比較、探索分析與模型選擇的說明
- 預先規劃與事後探索的區分
- 穩健性或敏感度分析

結果用語要符合設計。隨機實驗、自然實驗與觀察研究的因果識別條件不同；相關、迴歸係數或 SEM 路徑顯著，通常只支持關聯或預測敘述。問卷與 PLS-SEM 的進一步注意事項見[問卷調查法](method-survey.md)。

!!! warning "不要只留下最好看的模型"
    嘗試多種排除方式、變項定義或模型後，只報最顯著的一個，會讓不確定性看起來過小。保留分析歷程，說明主要模型的選擇依據，並把重要替代設定列入敏感度分析。

## 十、建立可重現紀錄

可重現不只表示有一份程式碼。另一位研究者還需要知道資料從哪裡來、以什麼順序執行、使用哪些套件版本，以及人工判斷發生在哪裡。

最低限度應保存：

- 原始資料或合法取得方式，以及版本識別
- 資料字典、分析計畫與變更紀錄
- 從匯入、清理、分析到製表的完整程式碼
- 執行環境、軟體與套件版本
- 隨機種子與非決定性步驟說明
- 不能公開的資料如何申請，以及可分享的模擬或遮蔽版本
- 決策日誌與人工覆核紀錄

### 10.1 交付前重跑

在乾淨環境依 README 從原始層重跑到最終表圖。核對論文中的樣本數、係數與圖表是否直接來自產出檔。若無法全自動化，人工步驟也要寫到別人能照做。

!!! note "可重現不代表可公開所有資料"
    私人、受限或含個資的資料仍須受控。可以分享欄位結構、資料字典、分析程式、模擬資料與申請流程；不能為了開放科學違反同意、契約或法規。

## 十一、可直接使用的分析前檢查表

- [ ] 研究問題、分析單位與資料列的單位一致
- [ ] 主要與次要分析已區分
- [ ] 資料字典記錄代碼、單位、缺失碼與轉換規則
- [ ] 原始資料設為只讀，清理流程可重跑
- [ ] 合併與排除前後都有筆數核對
- [ ] 遺漏值依來源與模式處理，不只看總比例
- [ ] 離群值先查原因，不以顯著與否決定去留
- [ ] 檢查的是所選模型真正依賴的假設
- [ ] 效果估計、區間與診斷和 p 值一起報告
- [ ] 事前分析與事後探索分開標示
- [ ] 論文表圖可由程式與紀錄重新產生
- [ ] 結論用語沒有超過研究設計能支持的強度

---

## 十二、本頁重點回顧

- 量化分析從研究問題、操作型定義與分析計畫開始，不從軟體選單開始。
- 資料字典要記錄變項語意、尺度、缺失碼、來源與轉換規則。
- 原始資料不覆寫；清理、排除、合併與衍生欄位都要可追溯。
- 遺漏值與離群值沒有跨情境的固定刪除門檻，處理方式取決於形成原因、模型與研究目的。
- 假設檢查應對準模型，並結合圖形、設計知識與正式診斷。
- 報告效果估計、不確定性、模型診斷與敏感度，不只報 p 值。
- 橫斷觀察資料通常支持相關或預測，複雜模型不會自動把關聯變成因果。
