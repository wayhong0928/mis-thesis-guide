# 研究的本質、歷程與時程

> 這一頁回答三個問題：做研究到底在做什麼？它要培養哪些能力？兩年的碩士生涯，每個階段該做到什麼？

---

## 一、做研究就是一個解決問題的過程

最精簡的一句定義：**做研究寫論文，就是一個解決問題的過程。**

這個過程有固定的骨架，而且骨架直接對應到論文的章節：

| 解決問題的階段 | 論文對應章節 | 這個階段在做什麼 |
|---|---|---|
| 問題探索 | 第一章 緒論 | 找到一個實務上重要、學術上有趣的問題 |
| 案例觀摩 | 第二章 文獻探討 | 前人怎麼做？做到哪裡？哪裡還不夠好？ |
| 方案構想與設計 | 第三章 研究方法 | 我打算怎麼做？為什麼這樣做是合理的？ |
| 方案執行 | 第四章 結果與分析 | 實際做出來的結果是什麼？ |
| 結果呈現與反思 | 第五章 結論與建議 | 這些結果代表什麼？限制在哪？下一步是什麼？ |

再怎麼樣都是**起承轉合**。整個歷程可以壓縮成一句話：

> 分析問題 → 提出方案 → 驗證效果 → 再分析問題 → …… → 最後形成知識。

### 1.1 研究的起點是文獻回顧，不是創意

一個常見的誤解是「做研究要先有靈感」。實際的順序恰恰相反：

1. 先從文獻回顧了解前人的失敗經驗與教訓，避免重蹈覆轍，藉此**降低風險**；
2. 接著吸收前人的智慧，站在巨人的肩膀上，**先立於不敗之地**；
3. 最後才是分析既有答案的缺點與不足，用自己的創意想出改進的辦法。

創意是用來走完最後一哩路的，不是用來當起點的。這是彭明輝《研究生完全求生手冊》反覆強調的核心觀點。

### 1.2 要讓什麼東西變得比較好？先有指標

有一句話值得貼在書桌前：**要讓什麼東西變得比較好，就必須先有一個指標。**

沒有績效指標，就沒有辦法宣稱「改善」；沒有辦法宣稱改善，研究就沒有可驗證的主張。所以：

- 你想改善什麼？（績效指標）
- 你打算怎麼改善？（研究方案／管理方案）
- 你要怎麼證明它真的比較好？（驗證設計）

管理類研究的「方案」通常是在探討**哪些變數之間的關係**；技術類研究的「方案」則通常是一個新的方法、模型或系統。但兩者都逃不掉「指標 → 方案 → 驗證」這個三段式。

## 二、學術著作的要件：什麼叫做「有價值的研究」

!!! note "想看更完整的版本"
    這一節（學術著作兩大要件、七項要件、貢獻的三個衡量角度）是把常見的判準整理成可對照的清單，**不是任何一本書的內容摘要**。
    相近的觀念在彭明輝《研究生完全求生手冊》裡有完整得多的論證與示範，本站只做通則式的重述（見[延伸閱讀與資源指南](sources.md)第二節與第四節）。

很多人到了寫論文才發現自己搞不清楚「為何而戰」，於是把時間花在沒有學術價值的事情上。學位論文有兩個基本要件：

**要件一：原創性（originality）或新穎性（novelty）。**
整本論文是為了報告過去學術界尚未發現的事實，或推翻、修正過去普遍相信的事實，或為既有問題找到更好的答案。個人讀書心得寫得再好，若不具備相對於學術界既有知識的新穎性，就沒有寫成論文的價值。

**要件二：嚴謹性（rigor）與客觀性（objectivity）。**
創見必須有可靠的證據與嚴謹論證來確保其客觀有效性，並以條理井然的方式寫成系統化的論述。這是「學術研究」與「偉大發明」的分野：發明只需要創意，學術研究還需要把創意變成經得起反覆檢證的系統化知識。

### 2.1 學術著作的七項要件

1. 原創性與貢獻
2. 可靠的證據支持
3. 批判性的檢視過程
4. 理論性、系統性與一致性
5. 客觀性與可重複性
6. 跟學術界有明確的關係與對話
7. 清晰的文體與敘述

這七項沒有一項是虛設的，每一項都有它要防堵的具體失誤。

### 2.2 貢獻怎麼被衡量

學術界通常從三個角度評價創新的價值：

- **廣度**：受這個發現影響的領域有多寬？被影響的人有多少？
- **強度**：對既有知識與實踐的衝擊有多強？改變或修正的幅度有多大？（徹底顛覆一個公認的定理，遠大於略微修正它）
- **難度**：完成它所需的創意與專業能力，有多罕見？

另一個殘酷但必須知道的規則：**一篇論文的「貢獻」＝它呈現的所有知識 −（減去）已被前人發表過的部分。** 就算研究完全是自己做的，只要在你交出草稿的前一天有人發表過，貢獻就完全屬於別人。

!!! warning "深而窄 vs 寬而淺"
    在相同研究成果的前提下，**深而窄的研究遠比寬而淺的研究有利**。研究子題要盡量系統化、連結成區塊，不要流於零星瑣碎，也不要輕易延長戰線。第一章宣告的研究範圍愈廣，你必須舉證負責的範圍就愈廣。

## 三、研究者的四大核心能力

不論工具怎麼演進，研究者的根本能力只有四項（這一組整理同時出現在彭明輝的書與 AI 輔助研究的方法論裡，可見它相當穩固）：

| 能力 | 內涵 | 為什麼 AI 取代不了 |
|---|---|---|
| **文獻回顧** | 透過大量閱讀，把模糊的題目收斂成真正的「問題」 | AI 能整理，但無法替你判斷哪一篇的框架真的適合你的情境 |
| **批判性思考** | 反覆推論、比較、質疑，評價證據與論述的可靠性 | 判斷本身就是研究的核心價值 |
| **知識管理** | 把碎片化的概念、數據、方法、反例組織成可終身使用的體系 | 體系的組織原則來自你的問題意識 |
| **邏輯表達** | 讓論證有邏輯、有結構，能說服他人 | 你講不清楚的東西，本質上還不是你的知識 |

### 3.1 批判性思考的六種能力

批判性思考包含：⑴分析、⑵評估、⑶推論、⑷解釋、⑸詮釋與解讀、⑹引導與組織自己的思考活動。

它不像數學或形式邏輯那樣有一套「照做就對」的操作程序。它更接近**默會知識（tacit knowledge）**：老師可以示範、可以帶著練，但同一班學生學完之後表現差距甚大。

**最關鍵的一點：批判性思考必須跟專業領域的知識結合。** 一個人對特定問題的背景知識愈充分、深刻、細膩，他在該問題上的批判性思考就愈周延。這也是為什麼「培養批判性思考」的最有效答案，是認真做完一個研究、認真寫完一本論文。

### 3.2 高階批判性思考的最省力捷徑

研究生確實很難看出大師級著作的不足。但是，**世界級的大師會在同一個研究主題裡彼此批判。**

只要認真彙整他們的相互批判，就可以獲得這個研究主題所需要的關鍵批判要領。具體來說，可以從既有文獻的三個位置蒐集：

- **導論**：每篇論文都會突顯自己的優點與既有文獻的缺失，而且措詞通常清晰易懂。
- **理論依據與研究方法**：會說明為何採取這個方法、其他方法哪裡不足或不適用。
- **結果的分析與討論**：作者示範了分析、論證與比較的技巧。

把這些討論彙整起來，你就擁有了一整套針對這個主題的批判清單，而且它的水準來自整個學術社群，不是來自你一個人的聰明。

## 四、研究的時間表：碩士兩年的階段性目標

《研究生完全求生手冊》提出的時程規劃相當具體，可以當作自我檢核的基準（實際依系所與指導教授的節奏調整）：

| 階段 | 目標 | 建議完成時間 |
|---|---|---|
| 第一階段 | 整理出既有文獻中的**共識與爭議**，以及各流派的特色與優缺點 | 碩一寒假結束前 |
| 第二階段 | 提出**創新的策略與研究構想**，完成可行性評估與完整的文獻回顧 | 碩一暑假結束前 |
| 第三階段 | 完成理論發展，彙整證據，反覆檢證與論證，調整假說、假設條件與適用範圍，直到有足夠貢獻且找不到弱點 | 約六至七個月 |
| 第四階段 | 示範案例設計、論文撰寫與修改、準備口試、口試後修訂 | 約三個月 |

!!! note "為什麼要盡早決定指導教授與研究主題"
    因為文獻回顧的時間有限。愈早鎖定主題，愈能把有限的閱讀時間聚焦在攸關研究題目的重點上。**先決定研究主題（較寬），再慢慢收斂到論文題目（較窄）。**

### 4.1 研究主題 vs 論文題目

這兩個詞經常被混用，但它們的關係是包含關係：

- **研究主題**（research topic）：一個較寬的領域或議題。一個主題底下包含非常多樣的論文題目，足以滿足各種不同的興趣與專長。
- **論文題目**（research problem）：明確到可以被嚴謹回答的具體問題。

選題目之前，先從較寬廣的視野了解該主題的背景、曾有過的題目類型、主要的爭議與共識，才能較踏實地解放創意。**只靠自己憑空想像，絞盡腦汁想出來的往往都是不具學術研究價值的題目。**

### 4.2 什麼是好題目

一句話：**實務上重要，學術上有趣。**

具體的線索包括：

- 不同篇論文出現**矛盾的結論**，就值得再檢驗一次，並找出造成矛盾的原因。
- 既有研究的**方法或證據不夠可靠**，可用更嚴謹的方法重做（「舊瓶新酒」）。
- 既有方法**還沒被應用到某個新領域或新情境**，而且理論上預期會有重大差異（「新瓶舊酒」）。

!!! warning "純粹的情境複製沒有學術價值"
    把一個先進國的研究架構原封不動複製到台灣，而沒有值得學術界關注的新發現，是缺乏創意與學術價值的。**你必須先找到一個文獻中不曾觸及的獨特要素，而且在理論上預示著它有機會造成重大差異，這樣的問題才值得研究。**

## 五、風險控管：研究不是賭博

研究就是探索未知，一定有不確定性，也就一定有風險。如果在提計畫書時就能清楚預測所有結果，繼續研究的必要性便需要重新說明。

風險控管的目的是**降低**風險，不是消除風險。實務上的四個要領：

1. **篩選構想時的四個判準**：⑴能否產出可被反覆檢視的確切結論？⑵能否整併成系統井然的區塊，而非零碎的發現？⑶是否優先發展學術價值較高的議題？⑷是否避開風險太高或可行性太低的議題？
2. **可行性評估**：證據取得的難易、成本與及時性；分析方法是否可行；設備、樣本、受訪者是否取得得到。
3. **備胎方案**：關鍵數據拿不到時的替代取得方式；研究成果不如預期時「退而求其次」可以下的較低階結論。
4. **戰略高地**：先找到一個近乎零風險的核心成果，立於不敗之地，再順著周邊議題擴大戰果。

!!! tip "研究成果不如理想時，不必立刻放棄"
    根據實際成果研判可以朝哪個方向下結論，「退而求其次」達成學術價值稍低但確實成立的結論，本身就是一種很好的備胎方案。此外，坦白承認限制、把研究限制寫得深刻，反而是加分項。

## 六、本頁重點回顧

- 做研究就是解決問題：問題探索 → 文獻回顧 → 方案設計 → 執行 → 反思，對應論文五章。
- 研究從**定義與衡量**開始；要宣稱改善，先要有績效指標。
- 學位論文的兩大要件是**原創性**與**嚴謹性／客觀性**；貢獻 = 全部內容 − 前人已發表的部分。
- 四大核心能力：文獻回顧、批判性思考、知識管理、邏輯表達。工具會變，這四項不會。
- 高階批判性思考的捷徑：**彙整大師之間的相互批判**，而不是靠自己憑空想。
- 深而窄優於寬而淺；宣告的研究範圍愈大，要防守的地盤就愈大。
- 好題目 = 實務上重要 + 學術上有趣；矛盾的結論是最好的切入口。
