# 研究倫理與資料管理

> 這一頁把研究倫理從「送一份表單」改成一套可執行的工作流程：先判定審查義務，再把同意、招募、風險與資料治理一路落實到結案。

!!! danger "先審查，再招募"
    只要研究會接觸人、取得可識別個人資料，或使用原本不是為本研究蒐集的資料，就應先查所屬機構的研究倫理與個資程序。需要審查的計畫，必須在核准後才招募或蒐集資料；不得先做完，再補送審。
    
    本頁是規劃地圖，不是法律意見，也不能代替研究倫理審查委員會（IRB／REC）的判定。

---

## 一、先拆成三個判斷

研究者常把「不是醫療研究」「問卷匿名」或「資料已經存在」當成不用處理倫理的理由。這些資訊只能協助判斷，不能直接得出結論。開始前要分別回答：

1. **研究是否涉及人或其資料？** 包含問卷、訪談、觀察、使用者測試、社群內容，以及可直接或間接辨識個人的次級資料。
2. **所屬機構要求走哪一種程序？** 可能是一般審查、簡易審查、免予審查的申請，或非人體研究的確認。名稱、適用條件與是否須取得證明，依各機構規定。
3. **即使不須倫理審查，是否仍有其他義務？** 個資法、資料提供者的使用條款、契約、著作權、保密約定與期刊政策仍可能適用。

```text
研究會接觸人或人的資料嗎？
│
├─ 否 ─→ 記錄判斷依據，仍檢查契約、著作權與資訊安全
│
└─ 是
   ├─ 先查本校 IRB／REC 的範圍與申請方式
   ├─ 送交研究計畫、招募、同意與資料管理文件
   └─ 取得正式判定或核准後，才依核准版本執行
```

!!! warning "免審不等於自己判定不用送"
    《人體研究法》列有得免審查的案件，但各機構如何確認、要不要申請證明，須看其程序。以臺大醫院研究倫理委員會為例，是否符合免審由委員會判定；這只能說明一種制度做法，不能直接套用到其他學校。你的學校如何處理：**待查證**。

---

## 二、倫理審查：送的不是題目，是完整做法

研究倫理審查關心的是研究參與者會經歷什麼、承擔什麼風險，以及研究團隊如何保護他們。常見送審文件包括：

- 研究計畫書與研究流程
- 納入、排除與停止條件
- 招募文案、接觸管道與酬謝方式
- 研究參與者說明及同意文件
- 問卷、訪談大綱、實驗刺激或系統操作內容
- 風險處理、申訴與緊急聯絡方式
- 資料管理計畫，包括保存、存取、分享與銷毀

### 2.1 執行中仍受核准版本約束

核准不是一次性的通行證。若要改招募對象、題目、同意方式、資料用途、第三方處理工具或保存期限，先確認是否須提出變更。偏差、疑似外洩、未預期風險與研究終止，也應依核准計畫及機構程序通報。

**實務做法**：所有送審文件都標示版本與日期，例如 `訪談大綱_v1.2_2026-09-04`。執行人員只能使用目前核准版本，舊版移入封存資料夾，不直接覆寫。

## 三、知情同意：是一段理解與選擇的過程

簽名只是留下證據，知情同意的核心是研究參與者在可理解、無不當壓力的情況下，自主決定是否參加。《人體研究法》第十四條列出的告知內容包括研究目的與方法、權益與個資保護、撤回方式、可預見風險、救濟措施，以及研究材料的保存期限與運用規劃。

一份可用的同意程序至少回答：

| 參與者會問的問題 | 應說清楚的內容 |
|---|---|
| 我要做什麼？ | 程序、時間、錄音錄影、可能追蹤次數 |
| 可能發生什麼？ | 不適、敏感揭露、名譽、就業、法律與隱私風險 |
| 可以不參加嗎？ | 自願參加、拒絕或退出不受不利待遇、退出方式 |
| 資料會怎麼用？ | 利用目的、分析方式、引用方式、分享對象與地區 |
| 誰看得到？ | 研究團隊、委外服務、資料庫或合作單位的範圍 |
| 會留多久？ | 保存期限、到期後封存或銷毀方式 |
| 有問題找誰？ | 研究團隊與獨立申訴窗口 |

!!! note "免除書面同意，不等於免除知情同意"
    線上勾選、口頭同意或免簽名，可能是經核准的同意形式；它們不代表可以省略說明與自主選擇。若研究擬免除部分或全部同意程序，應提出理由並由有權單位判定，不由研究者自行決定。

## 四、風險與招募：不要只看身體傷害

社會科學與資訊管理研究的主要風險，常出現在資訊與權力關係，而不是身體傷害。

| 風險面向 | 常見情境 | 可採措施 |
|---|---|---|
| 心理 | 回憶創傷、羞辱或壓力事件 | 允許跳題與停止；提供支持資源 |
| 社會與名譽 | 負面言論被同事或社群辨識 | 降低情境細節；限制逐字引述 |
| 就業與經濟 | 主管得知員工批評組織 | 由非主管招募；報告只呈現彙整結果 |
| 法律 | 回答涉及違規或爭議行為 | 減少不必要問題；事前界定保密限制 |
| 隱私與資安 | 名單、錄音或帳號外洩 | 分離識別碼；加密；最小權限 |
| 權力不對等 | 教師招募自己的學生、主管招募部屬 | 由第三方接觸；成績或考核完成後再招募 |

招募文案要與核准計畫一致，說清楚資格、活動、時間、酬謝、風險與聯絡方式。酬謝是補償時間與成本，不應高到讓參與者難以自由拒絕。若招募未成年人、受拘禁者、原住民族或其他可能受不當脅迫的群體，另有更嚴格的法規與程序，須向所屬機構查證。

**判斷風險時問兩次**：第一次問「單一欄位會不會傷害人」，第二次問「把欄位、逐字稿、時間地點與公開資訊合在一起後，會不會辨識出人」。

## 五、資料生命週期：收資料以前就決定終點

資料管理不是分析完才整理。先建立一份資料管理計畫（data management plan, DMP），把每一階段的產物、責任與處理方式寫清楚。

| 階段 | 要決定什麼 | 最少留下什麼 |
|---|---|---|
| 規劃 | 蒐集目的、資料類型、法規與責任人 | DMP、倫理判定、資料清單 |
| 蒐集 | 同意範圍、欄位最小化、傳輸方式 | 核准版本、蒐集紀錄、同意紀錄 |
| 儲存 | 位置、格式、加密、備份與權限 | 檔案命名規則、權限表、備份紀錄 |
| 處理 | 清理、轉錄、編碼與衍生資料 | 不覆寫的原始資料、處理腳本、變更紀錄 |
| 分析 | 版本、軟體環境與決策依據 | 可重跑的程式、分析日誌、資料字典 |
| 分享 | 誰能取得、提供哪個版本、用什麼授權 | 分享版資料、使用說明、風險評估 |
| 保存或銷毀 | 保存期限、典藏位置、核准銷毀方式 | 結案紀錄、銷毀或移交證明 |

保存期限沒有適用所有研究的單一數字。應同時查倫理核准、知情同意、所屬機構、經費補助、合作契約與投稿單位要求，採用能彼此相容的期限；不確定時標為**待查證**，不要自行填一個常見年限。

## 六、存取權限：能看資料的人愈少愈好

用「最小權限」規劃存取：每個人只取得完成工作所必需的資料與期間。最少做一張權限表：

| 資料 | 可存取角色 | 不應放在哪裡 |
|---|---|---|
| 聯絡名單與同意文件 | 主持人、核准的研究人員 | 共用聊天群組、公開連結 |
| 代碼對照表 | 指定保管人 | 與去識別資料同一資料夾 |
| 原始錄音／逐字稿 | 轉錄與分析人員 | 個人未加密裝置、一般 AI 服務 |
| 去識別分析檔 | 核准的分析人員 | 公開儲存庫，除非通過公開風險評估 |
| 彙整結果與可公開程式 | 依計畫決定 | 含密碼、金鑰或本機路徑的檔案 |

- 啟用個人帳號、強密碼與多因素驗證，不共用登入資訊。
- 原始資料至少有一份獨立備份；備份也要套用相同保護。
- 雲端、轉錄與生成式 AI 都是第三方處理。上傳前先查服務條款、資料位置、保留方式、模型訓練設定，以及同意與倫理核准是否涵蓋。
- 人員離開計畫、設備遺失或角色變更時，立即撤銷權限並留下紀錄。

## 七、去識別化與再識別風險

去識別化不是刪掉姓名就完成。能讓人被認出的資訊至少有三類：

1. **直接識別資訊**：姓名、電話、Email、學號、帳號、照片與聲音。
2. **間接識別資訊**：稀有職稱、精確地點、日期、年齡、組織與事件組合。
3. **自由文字與中介資料**：逐字稿中的故事、檔名、修訂者姓名、圖片 EXIF、錄音時間與裝置資訊。

### 7.1 三個容易混淆的處理

| 處理 | 還能否連回個人 | 管理重點 |
|---|---|---|
| 代碼化／假名化 | 持有對照表者仍可連回 | 對照表分開保管，仍按個人資料保護 |
| 去識別化 | 依情境降低辨識可能性 | 評估接收者、外部資料與未來技術造成的再識別風險 |
| 去連結 | 依《人體研究法》定義，永久不能以任何方式連結、比對 | 一旦完成就無法再聯絡個人或處理撤回要求 |

### 7.2 發布前做一次「有動機的辨識者」測試

假設一個有動機的人取得資料，他能否利用搜尋引擎、社群貼文、組織名錄或另一份資料集找到某位參與者？至少檢查：

- 稀有值與極小群組是否要合併、區間化或抑制
- 逐字引述能否被搜尋，是否需要改為不失原意的摘要
- 日期、地點、職稱與事件組合是否形成唯一指紋
- 公開版資料是否真的需要每一個欄位
- 一段時間後，外部資料增加是否提高再識別風險

!!! danger "分析用資料不等於公開用資料"
    團隊內可受控使用的資料，未必適合公開下載。公開分享前要另外產生資料版本、重新做再識別與傷害評估，並確認知情同意及核准範圍。不能安全公開時，可以只公開資料字典、分析程式與取得資料的申請程序。

## 八、可直接執行的流程

- [ ] 寫一頁研究流程，標出每次接觸人與資料的節點
- [ ] 查本校 IRB／REC 的適用範圍、程序、時程與表單版本
- [ ] 完成風險表、招募文案、同意程序與 DMP
- [ ] 取得正式判定或核准，記下核准版本與有效期間
- [ ] 設定資料夾、命名、備份、加密與權限表
- [ ] 訓練所有執行人員，確認只使用核准版本
- [ ] 蒐集期間記錄偏差、變更、事故與權限異動
- [ ] 分析時保留原始資料，讓清理與分析可重跑
- [ ] 發布前另做公開版資料與再識別風險評估
- [ ] 依核准計畫辦理結案、保存、移交或銷毀

發現誤傳、權限設錯或疑似外洩時，先停止傳輸與進一步利用，保存時間、檔案、服務與操作紀錄，再依校內程序聯絡指導教授、研究倫理、個資或資安窗口。不要自行掩蓋事故，也不要在沒有確認保存義務前刪除證據。

**主要查核來源**：

- [全國法規資料庫《人體研究法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0020176)：審查、研究對象權益、同意與研究材料管理的法規基礎
- [全國法規資料庫《個人資料保護法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=I0050021)：蒐集告知、特定目的、利用與安全維護
- [臺大醫院研究倫理委員會：免審案](https://www.ntuh.gov.tw/RECO/Fpage.action?fid=5536)：機構如何判定免審的一個實例，不能直接代替本校程序
- [UK Data Service: Foundations of research data management](https://ukdataservice.ac.uk/learning-hub/data-producer-support/foundations-of-research-data-management/)：資料生命週期與負責任分享
- [UK Information Commissioner's Office: How do we ensure anonymisation is effective?](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-sharing/anonymisation/how-do-we-ensure-anonymisation-is-effective/)：可辨識性與再識別風險評估

## 九、本頁重點回顧

- 倫理審查、個資義務、契約與著作權是不同判斷，通過其中一項不代表其他項目自動通過。
- 是否須審查、免審或非人體研究，應依所屬機構程序取得正式判定；需要審查時，核准前不得招募。
- 知情同意是一段理解與自主選擇的過程，不只是一張簽名表。
- 風險包括心理、社會、就業、法律與資訊安全；權力不對等也會破壞自願性。
- 資料生命週期從規劃、蒐集到保存或銷毀，每一階段都要留下決策與版本紀錄。
- 權限採最小化；第三方雲端、轉錄與 AI 服務都要先核對核准與同意範圍。
- 去識別化不是刪姓名。公開前要評估資料連結、自由文字與外部資訊造成的再識別風險。
