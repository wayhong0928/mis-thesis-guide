# 從零開始：研究所的第一個月

> 這一頁給剛入學、還不知道該做什麼的人。不談抽象的方法論，只談**你這個月該做的事**。

---

## 一、先搞清楚一件事：研究所跟大學不一樣

| | 大學 | 研究所 |
|---|---|---|
| 你的角色 | **消費**知識 | **生產**知識 |
| 成功的定義 | 學會別人已經知道的事 | 找出別人**還不知道**的事 |
| 誰給你標準答案 | 課本、老師 | **沒有人**。你要自己論證什麼是對的 |
| 主要輸入 | 上課 | 讀論文 |
| 主要輸出 | 考試、報告 | 一本要被答辯的論文 |

這個轉換是研究所最大的門檻，而且**沒有人會明講**。很多人到了碩二還在用大學的模式做事，等老師出題、等課本給答案、把讀完當成進度，然後在口試前發現自己沒有東西可以防守。

!!! note "一句話版本"
    大學問「這個怎麼學會」，研究所問「**這個我憑什麼說它是對的**」。

---

## 二、第一個月的五件事

### ① 決定指導教授

**這件事的優先序高於一切，而且愈早愈好。**

先查系所規定與實際時程；若當下尚不能選定指導教授，先確認可接觸的研究群與可能方向。

理由很現實：你的[文獻回顧](literature.md)時間有限，愈早鎖定方向，愈能把有限的閱讀聚焦在有用的地方。沒有指導教授，你連該讀哪一批文獻都不知道。

挑選時值得問自己的：

- 他最近三年在做什麼？（去查他的近期論文，不要只看實驗室網頁）
- 他帶學生的風格是什麼？（去問學長姊，這比什麼都準）
- 他的研究方法你學得來嗎？（要跑統計？要寫程式？要做田野？）
- 他一年帶幾個？你會分到多少時間？

### ② 建立工作環境

**在讀第一篇論文之前先做這件事**，否則你讀的東西會散落各處，三個月後全部要重來。

三個支柱，缺一不可：

| 支柱 | 做什麼 | 建議工具 |
|---|---|---|
| **文獻管理** | 存 PDF、自動產生引用格式、避免重複下載 | Zotero（免費開源）或學校授權的 EndNote |
| **筆記系統** | 每篇文獻一則筆記、可搜尋、可連結 | Obsidian、Notion、Heptabase 擇一 |
| **備份** | 雲端 + 本機，至少兩份 | 任何雲端硬碟 + 定期本機備份 |

詳細的工具比較與串接方式見[文獻管理與知識庫](tools-knowledge.md)。

!!! warning "最常見的第一個錯誤"
    「先讀一陣子再來整理。」
    **不會有那一天。** 讀了三十篇之後才想整理，你會發現想不起來哪篇講了什麼、哪些話是原文哪些是你的想法，只能全部重讀。
    **從第一篇就用系統。** 工具再爛都比沒有好。

### ③ 讀三篇東西

不要一開始就啃原創性期刊論文，你讀不懂，而且會誤以為問題出在自己。順序是：

1. **一篇你領域的回顧型論文（review article）**：建立領域地圖，知道有哪些流派
2. **一本同領域的碩士論文**：看格式、看章節、看一本合格的論文長什麼樣
3. **一篇你指導教授近三年的論文**：看他重視什麼、用什麼方法

第 2 項最常被跳過，但它的投資報酬率最高：**你要交的東西長什麼樣子，總得先看過一次。**

### ④ 修完學術倫理課程

多數學校要求修習[臺灣學術倫理教育資源中心](https://ethics-s.moe.edu.tw/)的課程並取得證書，而且**通常是提口試計畫書的前提**。

先查系所規定的課程、完成期限與認列方式。若確定需要，早點修完，不要等到要送計畫書才發現卡在這裡；也要把系所對生成式 AI 的使用規定查清楚（見[學術倫理與 AI 揭露](ethics.md)）。

### ⑤ 開始寫「研究日誌」

一個純文字檔就好。每次做了決定就記一行：

```
2026-09-04  決定跟 X 老師，方向大致是 ⟨…⟩
2026-09-11  讀了三篇回顧型論文，發現這個領域主要分兩派：⟨…⟩
2026-09-18  跟老師談過，他覺得 ⟨A 方向⟩ 太大，建議收斂到 ⟨B⟩。理由是 ⟨…⟩
2026-09-25  放棄 ⟨某方法⟩，因為樣本拿不到。改用 ⟨…⟩
```

**為什麼這件小事很重要**：一年後你要寫研究動機、要在口試回答「你為什麼選這個方法而不選那個」，這份日誌就是答案。沒有它，你只能事後編一個聽起來合理的理由，而口試委員聽得出來。

## 三、該讀什麼，依什麼順序

```
科普級 / 教導型文章     ← 完全不懂時從這裡開始
      ↓
回顧型論文（review）    ← 建立領域地圖
      ↓
同領域的碩博士論文       ← 看格式與完整結構
      ↓
各流派的關鍵論文         ← 這時候才啃原創性研究
      ↓
最新的近三年論文         ← 確認自己沒做重複的題目
```

**由寬而窄、由淺而深。** 反過來做（一開始就啃最難的原創論文）是最常見的浪費。

讀論文的具體技巧見[文獻回顧與批判性思考](literature.md)，包括「像剝洋蔥一樣讀」與「摘要 → 架構圖 → 問卷 → 緒論」的閱讀順序。

## 四、六個常見的錯誤起步

| 錯誤 | 為什麼是錯的 | 該怎麼做 |
|---|---|---|
| **等老師給題目** | 老師給的是**方向**，題目要你自己收斂。等下去只會浪費半年 | 主動帶著讀過的東西去找他討論 |
| **先學方法再找問題** | 「我想學 PLS-SEM，來找個題目用」；方法決定問題，就會做出沒有價值的研究 | 先確定要解釋什麼，方法自然浮現 |
| **想讀完所有文獻再開始** | 讀不完的。而且沒有問題意識時，讀了也記不住 | 帶著問題讀，讀到能問出好問題就夠了 |
| **把工具當進度** | 花三週研究 Obsidian 外掛，一篇論文都沒讀 | 工具夠用就好，選了就別再換 |
| **不記錄決策過程** | 一年後寫不出研究動機，口試答不出「為什麼選這個」 | 寫研究日誌（見上） |
| **太晚開始寫** | 「等資料收完再寫」；結果只剩兩個月寫五章 | 文獻探討邊讀邊寫；納入排除準則邊定邊寫 |

!!! tip "最後一項值得多說一句"
    **寫作不是研究的最後一步，是研究的一部分。**
    很多東西你以為想清楚了，一寫下來才發現有洞。愈早開始寫，愈早發現洞，愈有時間補。

## 五、兩年的節奏感

這是一個參考基準，實際依系所與指導教授調整：

| 階段 | 該完成什麼 | 大致時程 |
|---|---|---|
| **第一階段** | 整理出既有文獻的**共識與爭議**、各流派的特色與優缺點 | 碩一寒假前 |
| **第二階段** | 提出**研究構想**，完成可行性評估與完整文獻回顧 | 碩一暑假前 |
| **第三階段** | 完成理論發展、蒐集證據、反覆檢證與論證 | 約六至七個月 |
| **第四階段** | 論文撰寫與修改、準備口試、口試後修訂 | 約三個月 |

**如果你發現自己落後了**：不要加速讀文獻，先檢查是不是**卡在階段轉換**。很多人以為自己在做文獻回顧，其實是還沒定出研究問題（見[AI 輔助研究工作流](ai-workflow.md)的卡關診斷）。

## 六、你這個月該產出的第一份東西

不是論文，不是文獻筆記，是**一頁紙**，內容包含：

```
1. 我打算研究的大方向是什麼？（一句話）
2. 這件事在實務上為什麼重要？（一句話）
3. 這件事在學術上為什麼有趣？（一句話）
   （提示：矛盾的結論、方法不夠可靠、沒人做過某個情境）
4. 我目前知道這個領域主要分成哪幾派？
5. 我還不知道什麼？
6. 下個月我要讀哪五篇？
```

**寫得出來就可以去找老師談了；寫不出來就代表你還沒讀夠。**

這一頁在接下來一年會被改二十次，那是正常的。重點是它逼你把模糊的東西寫成具體的句子，[而模糊的東西寫下來就會露餡](writing.md)。

## 八、本頁重點回顧

- 大學是消費知識，研究所是**生產知識**，這個轉換沒人會明講。
- 第一個月的五件事：定指導教授、建工作環境、讀三篇東西、修學術倫理、開始寫研究日誌。
- **在讀第一篇論文之前先建好文獻管理系統**，否則三個月後全部重來。
- 讀的順序：科普 → 回顧型論文 → 碩博士論文 → 關鍵論文 → 最新論文。
- 六個錯誤起步中最貴的兩個：**先學方法再找問題**、**太晚開始寫**。
- 研究日誌是你一年後寫研究動機與回答口試的唯一素材。
- 這個月的產出是**一頁紙**，不是論文。寫不出來就代表還沒讀夠。
