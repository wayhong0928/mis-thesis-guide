# 質性研究方法

> 當學界對一個現象的認識仍相當有限、當你想知道「為什麼」與「怎麼發生的」，質性方法才是對的工具。它的嚴謹性標準與量化不同，但一樣嚴格。

---

## 一、什麼時候該用質性方法

**選它的三個典型理由**：

1. 學界對這個研究主題的認識仍相當**局限**，需要探索學界尚未意識到的潛在問題。
2. 你關心的是**機制、脈絡與意義**，而不是變數之間的強度。
3. 現象牽涉的因素複雜且交錯，先驗的假設架構可能會遺漏重要線索。

**不要選它的時機**：當你已經有成熟的理論與量表，而且問題是「效果多大」時，應採用量化方法。

!!! note "質性不必然比量化更有洞見"
    採用相同方法的研究，學術貢獻仍可能相差很大。關鍵往往在於：
    ① 理論基礎是否夠寬廣，還是流於零碎個案的堆砌；
    ② 研究問題有沒有扣緊該情境的**獨特性**。
    如果問題寬泛到幾乎適用於所有情境，得到的答案通常也難以展現特定脈絡的機制與意義。
    **問錯了問題，就很難有好的答案。**

---

## 二、常見的質性取徑

| 取徑 | 核心關懷 | 資料來源 | 產出 |
|---|---|---|---|
| **深度訪談** | 當事人的經驗與詮釋 | 半結構式訪談逐字稿 | 主題與模式 |
| **個案研究** | 真實脈絡中的複雜現象 | 多來源（訪談、文件、觀察、檔案） | 個案內與跨個案的解釋 |
| **紮根理論** | 從資料中長出理論 | 訪談為主，理論抽樣 | 一個實質理論 |
| **民族誌／參與觀察** | 文化與日常實作 | 田野筆記 | 厚描述 |
| **文件與內容分析** | 文本中的意義與結構 | 政策文件、貼文、報告 | 編碼架構與分布 |
| **反思文本分析** | 書寫者的認知歷程 | 反思日誌、學習歷程 | 反思層次的診斷 |

---

## 三、抽樣與資料蒐集

質性研究的取樣方式要配合研究取徑與問題。目的性取樣常用來尋找能提供相關經驗的參與者；**理論抽樣（theoretical sampling）**則主要適用於紮根理論，研究者會依分析中逐步形成的概念決定後續取樣。它不是所有質性研究的通則，也不以降低量化意義的抽樣偏差為目的。

方法章要交代：

- 遴選受訪者的**原則、方法、步驟與背後的理論依據**
- 受訪者的**總人數與特徵分布**
- 訪談的**平均時間**與總體規模（逐字稿頁數或字數）
- 何時、為何停止收案；採紮根理論時，另交代理論飽和的判斷依據

!!! warning "樣本數少不是原罪，樣本結構鬆散才是"
    只追求參與者背景分布廣泛，卻說不清各類型與研究問題的關係，仍不足以支持研究結論。
    質性研究的說服力來自**樣本結構與研究問題的對應**，不是人數。

### 3.1 資料蒐集流程

方法章至少要交代招募與同意程序、訪談或觀察指引如何形成、資料在何時何地以何種方式取得，以及錄音、轉譯、匿名化與保存方式。資料蒐集與初步分析通常會往返進行；若分析結果改變後續提問或取樣，也要留下決策紀錄。具體程序仍須依研究取徑與倫理審查要求調整。

## 四、編碼與分析

### 4.1 紮根理論的三層編碼

| 階段 | 做什麼 | 可否請 AI 協助 |
|---|---|---|
| **開放編碼** | 逐行拆解資料，賦予概念標籤 | 可提供分類或命名提示，研究者逐項核對 |
| **主軸編碼** | 把概念歸納成範疇，找出範疇之間的關係 | 應由研究者主導 |
| **選擇性編碼** | 選定核心範疇，整合成理論 | **必須由研究者主導** |

**迭代式編碼**是關鍵動作：時而將資料**簡化**（歸納出更抽象的概念），時而將資料**複雜化**（重新拆解、追問細節），以便既開放又有秩序地把研究觸角伸展到事前未曾預期的角落。

三層編碼是紮根理論的分析程序，不能直接套用到所有質性取徑。重複檢視資料有助於比較前後判斷，但次數本身不能保證精準或完整；研究者仍須說明編碼如何修正，以及判斷依據。

### 4.2 反思文本的深層分析

處理反思日誌、學習歷程這類文本時，有兩個傳統文字分析難以觸及的層次：

- **消極證據分析（negative evidence）**：找出文本中「沒寫、但不代表沒發生」的訊息，例如作者可能選擇性遺忘、合理化，或刻意避開某些內容。
- **隱含語義分析（implicit semantics）**：讀出語句背後的態度、認知與推論痕跡。

可結合 **Kember 反思思考模型**的四個層次做分層編碼：

```
描述（describing） → 理解（understanding） → 反思（reflection） → 批判性反思（critical reflection）
```

!!! tip "AI 只能提供敏感度與分類提示"
    編碼架構仍須由研究者建立、說明並持續修正。AI 可以提示可能遺漏的語句、分類方式或替代命名，但這類提示不等同真人研究者的獨立編碼，也不能直接算作編碼者間信度。
    AI 的輸出還可能抹平資料的微妙差異。所有提示都要回到原始資料逐項核對，核心範疇與詮釋責任仍由研究者承擔。

## 五、信實度（Trustworthiness）

質性研究不用「信度效度」的量化語言，而用 Lincoln 與 Guba（1985）提出的四個對應判準：

| 判準 | 對應的量化概念 | 常見作法 |
|---|---|---|
| **可信性（credibility）** | 內部效度 | 三角驗證、成員檢核（member checking）、長時間投入、同儕檢視 |
| **可轉移性（transferability）** | 外部效度 | 厚描述（thick description），讓讀者自行判斷可否轉移 |
| **可靠性（dependability）** | 信度 | 稽核軌跡（audit trail）、完整記錄研究決策 |
| **可確認性（confirmability）** | 客觀性 | 反身性陳述（reflexivity）、原始資料保留、研究者立場交代 |

### 5.1 三角驗證是黃金標準

- **資料三角**：不同來源的資料（訪談 + 文件 + 觀察）
- **方法三角**：不同方法（質性 + 量化）
- **研究者三角**：不同研究者獨立編碼後比對
- **理論三角**：用不同理論視角詮釋同一組資料

**AI 不能替代第二位真人研究者的角色，也不構成研究者三角驗證。**

### 5.2 反身性：交代你自己

質性研究者本人就是研究工具。因此必須交代：

- 你與研究場域、受訪者的關係
- 你的先前經驗與可能的預設立場
- 這些立場可能如何影響資料的蒐集與詮釋
- 你採取了什麼措施降低這種影響

在人類學等取徑裡，口試委員可能會要求你**清楚區辨自己的觀察中哪些可能受到個人主觀因素影響**。

## 六、結果與討論怎麼寫

質性研究的「結果與討論」需要用較多文字連結主題、證據與解釋。圖表可以輔助整理，但不能取代對脈絡與例外的論證，這是寫作時的主要挑戰。

### 6.1 量化與質性的結構差異

| | 量化 | 質性 |
|---|---|---|
| 論證形狀 | **樹狀**，向一個明確結論收束 | **網狀**，多元發現彼此交錯 |
| 主要呈現 | 數值、圖表與模型結果 | 主題、引文、脈絡與解釋 |
| 執筆難度 | 相對容易掌握 | 沒有適當聚焦就容易蕪雜、瑣碎 |

### 6.2 下筆前的三個動作

1. **評量所有的發現**，以及它們各自能支持的結論
2. **審慎評估學術價值**，據以決定取捨與輕重
3. **根據論證時所需的呼應關係**，組織各項發現與論證的次序

有了這個架構，才能寫出提綱挈領且眉目清晰的結果章。

### 6.3 引用受訪者原話的紀律

- 每一段引文都要有**編號與必要的來源標記**（如 P07、群組 A）；標記程度須兼顧分析需要與去識別
- 引文是**證據**，不是裝飾。引完必須有分析，不能引完就跳下一段
- 不要只引支持你論點的話；**反例（negative case）的處理反而最能展現嚴謹度**
- 引文要保留受訪者的口語樣態，但可標註刪節與補充

### 6.4 一個好的質性發現長什麼樣子

質性研究最有價值的產出，往往是**推翻了原本的二分法**。

例如，既有研究對某種行為有相互矛盾的描述。訪談後可能發現，表面上相同的行為其實出於不同限制、理解與動機。此時，研究問題就能從「這個行為是否發生」轉向「哪些機制會產生外觀相似的行為」。

**這種「把單一標籤拆解成多元機制」的發現，是質性研究最擅長、也最難被量化方法取代的貢獻。**

## 七、混合方法

資管研究常見兩種組合：

| 設計 | 順序 | 用途 |
|---|---|---|
| **解釋性序列設計** | 量化 → 質性 | 用訪談解釋量化結果中的異常或反直覺發現 |
| **探索性序列設計** | 質性 → 量化 | 先用訪談發展構念與題項，再用問卷驗證 |
| **同時嵌入設計** | 並行 | 主方法為主，另一方法補強特定面向 |

一個實際的例子：在問卷編製前，先進行專家或使用者的質性訪談來歸納關鍵變數，再據以設計題項。這樣做出來的量表，構念效度的辯護會強很多。

!!! warning "整合邏輯必須是你的原創論證"
    AI 可以協助兩階段之間的資料整合摘要，但「為什麼質性結果能解釋量化的異常」這個論證，必須由你自己完成。混合方法論文最常見的失敗，是把兩份研究裝訂在一起，卻沒有真正的整合章節。

---

## 八、本頁重點回顧

- 質性適合探索機制與意義；當認識有限、現象複雜時最有價值。
- 抽樣須配合研究取徑；理論抽樣與理論飽和主要適用於紮根理論。
- 編碼要迭代，並留下分類與修正的判斷依據。
- 信實度四判準：可信性、可轉移性、可靠性、可確認性。
- 三角驗證是黃金標準；AI 不能取代第二位真人研究者。
- 質性的論證是網狀的，下筆前必須先取捨與排序。
- 引文是證據不是裝飾；反例的處理最能展現嚴謹度。
- 最有價值的質性發現，往往是**把單一標籤拆解成多元機制**。
